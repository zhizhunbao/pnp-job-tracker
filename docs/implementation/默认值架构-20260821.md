# 默认值架构 —— 边界收窄只做一次,空值决策用词说话

> 2026-08-21。起因:Frank 两处实拍 ——「query 该返回处理完默认值的 type 对象」、
> 「functions 每个函数都有很多默认值处理的判断」(连 `toRequirement` 映射函数本身也满身三元)。
> 样张已落地并上生产:`b5e4962c`(lib/db 词汇表 + consult 十条查询换装)。
> **本文把样张升格为全站规矩:判据、边界、闸、迁移批次。** 闸未开工,等点头。

## 1 · 病与判据

**病**:`String(r.x ?? '')` / `Number(r.x ?? 0)` / `x == null ? null : Number(x)` 三个成语
散在每个取数循环里(盘点见 §5,全站 ~122 处)。三重代价:

- **重复**:同一列的收窄各写各的(实撞:`NOC_TITLE_TEER` 的 title/teer 在三处各写一遍);
- **红线靠人记**:`?? 0` 用在官方可空的列上就是替官方编数(实撞:ops 隐私抑制值差点折 0;
  SIRS 池「10 件」被模型说成「10 天」也是同族 —— 语义信息在收窄时丢了);
- **读不动**:业务函数里一半行数是收窄仪式,读的人翻不到业务。

**判据**(全文只有这一条):**数据跨边界进来时收窄一次,之后全程干净。**
边界 = 库行、外部 API 回包、用户输入。不跨边界的代码不许再出现收窄成语。

## 2 · 架构:三层

```
┌ 词汇表(lib/db,共享叶子)──── text / count / numOrNull:空值语义即 API
├ 行形状 + 映射函数(各域)──── XxxDbRow(types.ts,逐列声明可空)+ toXxx(functions.ts)
└ 闸(eslint local 规则)────── 收窄成语只许出现在映射函数里,别处红
```

### 2.1 词汇表(已落地,`lib/db/database.ts`)

| 词 | 语义 | 用错的样子 |
|---|---|---|
| `text(x)` | 脏字符串 → `''`。显示与拼接兜底,永远无害 | — |
| `count(x)` | 计数 → `0`。**只给「个数」列**:「一个都没有」本身是答案 | 用在分数/金额列 = 替官方编数 |
| `numOrNull(x)` | 官方可空的数值 → **保 null**(隐私抑制值、没公布的分数、`rule` 行阈值) | 这类列上看见 `count()` 就是 bug |

- 为什么不给 `query<T>` 加泛型:TS 类型运行时不存在,泛型是「声称」不是「校验」,
  骗人的泛型比 `any` 危险(database.ts 头注释旧账同款)。
- 为什么不做声明式 codec(spec 派生类型+映射):每个 spec 只有一个消费者,
  「没数出重复不抽公共」;真重复(成语)词汇表已收掉。TypeBox 的 cast 语义与 null 规矩对不上,弯它更贵。
- 词汇表**封口三个词**。要加第四个词,先回答:它的空值语义与前三个哪里不同,写进本节表格再加。

### 2.2 行形状 + 映射函数(样板:consult)

- **一条 SQL 一个行形状**(`XxxDbRow`,住消费它的域的 types.ts):逐列声明、全可空、
  **JSDoc 写明哪些列官方可空**(那是 `numOrNull` 的名单);
- **一条 SQL 一个映射函数**(`toXxx`,住 functions.ts):体内只有一个 return 对象,
  每格一个词。业务循环拿到的就是干净 type 对象;
- 非 DB 边界同规矩:外部 API 回包(pi 事件、Stripe webhook)、`users.profile` 这类 json 列,
  进域第一行收窄成本域形状 —— consult 的 `beforeToolCall` 收窄 `unknown`、route 的档案映射即先例;
- **出边界的显示格式化不算收窄**(`String(row.open)` 拼 valueText、错误信息 `String(e)`)——
  它们是「干净值 → 字符串」,不是「脏值 → 干净值」,不在闸的射程里。

### 2.3 闸(草案,等点头再实现)

`local/no-inline-coercion`:在名单内的域文件里,`?? ''`、`?? 0`、
`== null ? null : Number(…)`、`String(x ?? …)` 只许出现在 `to*` 命名的映射函数体内与
`lib/db/database.ts`,别处报错并指路词汇表。滚动开闸(同 no-comment-in-function 惯例):
**迁完一个域加一个名单**,首批 = `consult` + `db`(现在就是 0 违规,闸拦的是明天新写的那行)。

## 3 · 哪格用哪个词(逐格判,不许一刀切)

1. 先问:**这一列在官方语义里可以没有值吗?**
   可以(分数线、邀请数、阈值、TEER、隐私抑制值)→ `numOrNull`,消费端念 `valueText` 原文;
2. 不可以,且是**个数**(在招数、条数)→ `count`;
3. 字符串一律 `text`;
4. 拿不准 → `numOrNull`。**宁可下游多判一次 null,不给官方编一个 0。**
