# 默认值架构 —— 保证在数据层给足,下游不再处理默认值

> 2026-08-21。起因:Frank 三处实拍 ——「query 该返回处理完默认值的 type 对象」、
> 「functions 每个函数都有很多默认值处理的判断」、**「这些都应该在上层处理好」**。
> 第三句把方向定死:词汇表+映射函数(`b5e4962c`,已上生产)只是**过渡态** ——
> 它在下游补偿上游没承诺的保证。终态是把保证放回数据层,本文按终态重写。

## 0 · 证据:2026-08-21 生产库逐列空值审计

六张 consult 消费表逐列数 null,结论一边倒:

- **全部文字列从不空**(province/stream/label/url/fetched/value_text/…,含 307 行的
  pnp_requirements 二十多列)—— ETL 早就把它们写实了,只是 DDL 没写 NOT NULL,
  于是 TS 那头不敢信,~122 处 `?? ''` 全是替 schema 还债;
- **确有空的列恰好全是「空即语义」**:score(53)/scale(40)/invitations(3)/value(12+41)/
  points(22)/draw_crs(2)/applies_family_size(286)—— 官方没公布,**该空**,
  这不是默认值问题,是数据本身。

---

## 1 · 病与判据

**病**:`String(r.x ?? '')` / `Number(r.x ?? 0)` / `x == null ? null : Number(x)` 三个成语
散在每个取数循环里(盘点见 §5,全站 ~122 处)。三重代价:

- **重复**:同一列的收窄各写各的(实撞:`NOC_TITLE_TEER` 的 title/teer 在三处各写一遍);
- **红线靠人记**:`?? 0` 用在官方可空的列上就是替官方编数(实撞:ops 隐私抑制值差点折 0;
  SIRS 池「10 件」被模型说成「10 天」也是同族 —— 语义信息在收窄时丢了);
- **读不动**:业务函数里一半行数是收窄仪式,读的人翻不到业务。

**判据**(全文只有这一条):**数据跨边界进来时收窄一次,之后全程干净。**
边界 = 库行、外部 API 回包、用户输入。不跨边界的代码不许再出现收窄成语。

## 2 · 架构:四层(保证逐层上移,下层只剩语义)

```
层1 ETL/mart   文字列写实、计数列写实 —— 审计证明已经做到,不许倒退
层2 DDL        对「从不空」的列上 NOT NULL(docs/sql 手写先行)——
               保证从「惯例」变成机器承诺;脏数据在 seed 当场炸,不再静默流到用户
层3 行形状     XxxDbRow 里这些列声明成不可空 —— text() 包装随之整批删除
层4 域代码     只剩两件真事:数值列的驱动转换(pg 把 numeric 回成字符串)与
               「空即语义」列的 null 透传(numOrNull)—— 那是业务事实,不是默认值
```

- 层3 的词汇表(text/count/numOrNull)在层2 落地前是**过渡态**;落地后 `text()`
  大批消失(不需要了),留下的 `numOrNull` 改名实义 —— 它处理的是数据不是缺省。
- 层4 有一个残余:pg 驱动把 numeric/bigint 回成字符串。全局改 pg 的 typeParser
  会波及 Payload 自己的查询(池是它的),**不动** —— 数值转换留在映射函数里,
  它是类型转换不是默认值。

### 2.1 词汇表(已落地,`lib/db/database.ts`)

| 词 | 语义 | 用错的样子 |
|---|---|---|
| `text(x)` | 脏字符串 → `''`。显示与拼接兜底,永远无害 | — |
| `count(x)` | 计数 → `0`。**只给「个数」列**:「一个都没有」本身是答案 | 用在分数/金额列 = 替官方编数 |
| `numOrNull(x)` | 官方可空的数值 → **保 null**(隐私抑制值、没公布的分数、`rule` 行阈值) | 这类列上看见 `count()` 就是 bug |
| `show(x)` | **出边界**:干净可空数值 → 显示串,null → ''(numOrNull 的显示端配对) | 拿它洗脏行 = 方向用反 |

- 为什么不给 `query<T>` 加泛型:TS 类型运行时不存在,泛型是「声称」不是「校验」,
  骗人的泛型比 `any` 危险(database.ts 头注释旧账同款)。
- 为什么不做声明式 codec(spec 派生类型+映射):每个 spec 只有一个消费者,
  「没数出重复不抽公共」;真重复(成语)词汇表已收掉。TypeBox 的 cast 语义与 null 规矩对不上,弯它更贵。
- 词汇表**封口**。要加新词,先回答:它的空值语义与已有的哪里不同,写进本节表格再加
  (`show` 即按此程序进表:闸抓到 pointsFacts 的出边界格式化,语义确实独立 —— 前三个收进来,它送出去)。

### 2.2 行形状 + 映射函数(样板:consult)

- **一条 SQL 一个行形状**(`XxxDbRow`,住消费它的域的 types.ts):逐列声明、全可空、
  **JSDoc 写明哪些列官方可空**(那是 `numOrNull` 的名单);
- **一条 SQL 一个映射函数**(`toXxx`,住 functions.ts):体内只有一个 return 对象,
  每格一个词。业务循环拿到的就是干净 type 对象;
- 非 DB 边界同规矩:外部 API 回包(pi 事件、Stripe webhook)、`users.profile` 这类 json 列,
  进域第一行收窄成本域形状 —— consult 的 `beforeToolCall` 收窄 `unknown`、route 的档案映射即先例;
- **出边界的显示格式化不算收窄**(`String(row.open)` 拼 valueText、错误信息 `String(e)`)——
  它们是「干净值 → 字符串」,不是「脏值 → 干净值」,不在闸的射程里。

### 2.3 闸(✅ 2026-08-21 已立,Frank 拍板「先写检查,基于检查出来的内容一点一点改」)

`local/no-inline-coercion`(eslint.config.mjs):三个成语 —— `String(x ?? …)`、
`Number(x ?? …)`、`x == null ? 字面量 : Number/String(x)` —— 是「库行没洗就地补」的形状;
普通的 `a ?? b` 可选回退不在射程。开闸:**consult = error**(守已迁的),
**全站其余 = warn**(= 整改清单,首扫 123 处),迁完一个域升一个 error;
`lib/db/database.ts` 豁免(词汇表自己就是这三个成语的家)。
立闸半小时的战果:抓到 pointsFacts 一条真漏网 → 催生了 `show` 这个词。

**pre-push 钩子**(Frank 拍板「git push 之前先要过一遍 eslint,自动触发」):
`.githooks/pre-push` 只查本次要推的 cms 改动文件,`--quiet` 只拦 error;
每个 clone 一次性 `git config core.hooksPath .githooks` 生效(本机已设)。禁 `--no-verify`。

## 3 · 哪格用哪个词(逐格判,不许一刀切)

1. 先问:**这一列在官方语义里可以没有值吗?**
   可以(分数线、邀请数、阈值、TEER、隐私抑制值)→ `numOrNull`,消费端念 `valueText` 原文;
2. 不可以,且是**个数**(在招数、条数)→ `count`;
3. 字符串一律 `text`;
4. 拿不准 → `numOrNull`。**宁可下游多判一次 null,不给官方编一个 0。**
