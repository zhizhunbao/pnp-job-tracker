## 0. 调研结论(2026-07-30 实测 postings.json,62,255 帖)

**两个病灶,不是一个:**

1. **计次/计程价被兜底当成时薪年化**(榜首直接来源)。04d 单位判断链没命中任何时间单位词时,
   走 `hi<2000 → hr` 兜底。「mobile disc jockey **$400–$500 per night**」被当 $450/hr ×2080 =
   **$936,000**,全库第一。同类:`$.30 commission per kilometre` → $62,400(per km/mile 计程价共 ~20 帖)。
2. **真时薪但超高,×2080 数学对、语义错**。$300–400/hr 验光师折 $728K、$200–400/hr 医生折
   $520–624K——这些是**出诊/计费价**,医生不按 2080 小时计费全年;还混着可疑帖($200–300/hr 的
   "software developer"/"IT analyst")。时薪折算超过 $150/hr 等值的共 **32 帖**,前 20 名全是此类。
   对照组:**真高薪岗直接标 annually**(皮肤科医生 $550K–$850K annually → $700K),不受影响。

**ESDC 中位佐证(否决方案③的关键)**:wages.json 里 NOC 31101(专科医生)中位时薪本身就
$200–244/hr——ESDC 自己的口径也是计费价。即「高时薪」对这些职业**不是异常值**,异常的是
**×2080 这个动作**;按「中位 N 倍」做 sanity 根本拦不住($300/hr ÷ $244 中位 < 2 倍,照样折出 $72 万)。

## 0'. 三方案对比(选 ①+计次价修复)

| 方案 | 判定 | 理由 |
|---|---|---|
| **① 时薪>阈值置空 + 计次价不年化** | ✅ 选定 | 循「宁可留空不瞎猜」既有口径(04d 三道护栏、09 评分注释同款);改动全在 04d 十来行,零 schema 变更;salaryText 保留「$300–$400/hr」诚实展示,只是不再冒充年薪参与排序 |

| ③ 按 NOC 的 ESDC 中位做 sanity 区间(超 N 倍不折算) | ✗ | 见 §0:医生中位时薪本身 $200+,倍数检查拦不住目标病例;还给纯字符串清洗层引入 NOC×wages 数据依赖(04d 跑在 NOC 判定链之外,ATS 岗无 NOC) |

**阈值取 $150/hr**:×2080 = $312K。实测 >$150 的 32 帖全是出诊价/计次价/可疑帖,无一真雇佣年薪;
$100–150/hr 区间(107 帖)是真实高级岗(折算 ≤$312K,合理保留)。

## 1. 整体目标

/jobs 年薪排序与 /start 高薪榜的头部只由**帖面可信的年薪**构成:
- 计次/计程价(per night/km/mile/piece…)不年化(基数不是时间);
- 时薪中点 >$150/hr 只展示时薪文本,不折年薪;
- 命中护栏的岗 salaryAnnual=NULL → 排序 NULLS LAST 自然沉底,vs-中位/评分薪资项同步留空(诚实降级)。
