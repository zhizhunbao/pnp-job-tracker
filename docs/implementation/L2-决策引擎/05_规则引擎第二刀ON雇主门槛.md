# L2-05 规则引擎第二刀:ON(OINP)雇主门槛 + 技工语言分档

> 承接 [L2-04](04_规则引擎第一刀BC门槛.md) §6 后续①。设计源头是
> [规则引擎与题库配对](../../design/规则引擎与题库配对-20260731.md) §3.5:
> Frank 2026-07-31「现在 OINP 对雇主也有要求了」——`subject='employer'` 这一维就是为它留的。

## 1. 目标与非目标

- 目标:ON Workforce Priority 通道的官方门槛入库,**雇主侧三条**(经营年限/营业额/雇员数)进报告;
  顺带把同两页上能可靠解析的申请人侧三条(语言分档、免考条款、工资档)一起收。
- 非目标:**ON 的工作经验不收**(官方三套并行且绑定「同一雇主同一岗位」:近 12 个月内连续 6 个月 /
  安省应届 3 个月 / 部分职业近 5 年累计 2 年 —— 本站问的是通用经验,对不上就不硬套,留空=不收录);
  ON 新的 EOI 打分表(见 §6)。

## 2. 方案

### 2.1 数据层:`etl/pnp/build_on_req.py` → `data/raw/pnp/on-req.json`(11 条)

两个官方页(ontario.ca httpx 直连 200):通道页出申请人侧、雇主指南出雇主侧。

| 落到谁 | 因素 | 值 |
|---|---|---|
| 申请人 | language | TEER 0-3 非技工 **CLB 6**;TEER 0-3 技工 **CLB 5**;TEER 4/5 **CLB 4** |
| 申请人 | languageExempt | 近 3 年安省院校指定学历可免考(**只陈述不判定**——本站没问学历) |
| 申请人 | wage | `basis=occMedian`:不低于该职业该地区的中位工资档 |
| **雇主** | empYears | 在营 ≥3 年 |
| **雇主** | empRevenue | GTA **$1,000,000** / 官方点名普查区 **$500,000** / 其余 **$250,000** |
| **雇主** | empStaff | GTA ≥**5** 名、GTA 外 ≥**3** 名(须公民或 PR,周 30 小时以上) |

自校硬闸:任一组没解析到 → 保留旧表 exit 1;另加**档位合理性**校验(营业额必须 GTA>普查区>其余、
雇员数 GTA>外)—— 两列读反了会把门槛说低,比没有更危险。

### 2.2 引擎新增的三件事(`lib/rules.ts`)

1. **NOC 前缀作用域**(新列 `applies_noc` / `excludes_noc`,DDL `docs/sql/e13-02-*.sql` 纯 ADD):
   ON 的技工低档存官方大组码 `72,73,82,83,93,6320,62200`,排除 `726,932`。
   引擎按**前缀命中长度**取最具体的一行 —— 技工那条是通用条款的例外,不是并列条款。
2. **`basis=occMedian`**:阈值不是绝对数,取该职业该省的官方中位年薪当 need;报告层没有具体岗位 →
   verdict 恒 unknown。这条的价值不在判定,在于把「拿到 offer 该对着哪个数看」写清楚。
3. **分档因素按阈值大小取高低档,不认省专有的区域名**:BC 叫 metro-vancouver/rest-of-bc、
   ON 叫 gta/outside-gta,按名字挑行等于每加一个省改一次引擎。区域名原样带进 `tiers` 给显示层。

### 2.3 显示层

`rpt.r.emp.staff` 拆成 `.metro`(BC 说「大温」)与 `.gta`(ON 说「GTA」)—— 同一件事两套官方地名,
按最高档的区域名选句子。营业额用 `$1M` 而不是 `$1000K`(官方原文就是 $1,000,000)。

## 5. 风险与回退

- **官方改版**:两页都是网页(不像 BC 有 PDF 版本号),ontario.ca 改文案就可能解析空 →
  自校 exit 1 保留旧表,不会静默写坏;**ON 没有官方生效日期**(`guideEffective` 留空),
  过期只能靠 `fetched` 判断,这是已知弱点。
- **免考条款是已知的假阴性来源**:安省应届生本可免考,报告仍会说「差一档」——
  所以单独出了一行说明。等学历题进题库,这条升级成真判定。
- **回退**:删 `on-req.json`(或从 `IN_REQ_TABLES` 摘掉)+ 清 ON 行,报告立刻回到只有 BC 的状态。
