## 2. 方案

### 2.1 引擎层:`gateReport`(lib/report.ts 新增纯函数,单测锁行为)

```ts
type ReportLane = { kind: 'prov'|'ee'|'alts'; verdict; key; params }   // 三卡摘要(判定词=事实,免费)
type GatedReport = Report & { lanes: ReportLane[]; hint?: ReportLine; locked: string[]; pro: boolean }
gateReport(report, pro): GatedReport
```

- **免费**:conclusions 只留前 2 条(引擎顺序天然=清单命中+抽选区间,正合 v2c);gaps/nextSteps 全给
  (钩子与引流);alternatives 清空;被裁内容归并成 `locked` 类别键(有序去重):
  `score`(scoreAbove/Below/Band、answerScore 覆盖省)/ `window` / `alts` / `ee` / `more`。
  **锁行只出引擎真能算的类别**——window 无 pgwp 不出、alts 为空不出(不卖不存在的东西)。
- **hint**(hero 卡点短句,免费):取 regulated/expShort 类第一条(「说中他没说出口的事」必须在免费层)。
- **lanes**:省提名卡=目标省首条省结论的判定;EE 卡=ee 结论判定;备选卡=`{count, first}`(数量与首省是事实)。
- **Pro**:locked=[],全量下发。
- 引擎小改:REGULATED 分支往 nextSteps **头部**加 `rpt.n.cert`(NNAS url)——v2c 下一步 ① 是认证。
- **红线:裁剪在服务端**。免费响应里没有锁区正文,devtools 看不到(与 PRO_COLUMNS「SELECT 源头裁掉」同哲学)。

### 2.2 API:/api/report 接 isPro

`const pro = isPro(await getUser(headers))` → 返回 `gateReport(buildPrReport(...), pro)`。lib/entitlement 现成,无新表无新列。

### 2.3 探索题第一批(lib/questions.ts 加 `PR_EXPLORE_SURVEY`)

铁律「每题必改结论」筛选后只上两题(学历/法语引擎暂无规则,**不加**):
- **CRS 档**(没算过/<400/400-450/450+ → null/380/425/480)→ 改 eeAbove/eeBelow 结论;
- **签证剩余**(<6 月/6-12 月/1-2 年/2 年+ → 4/9/18/30)→ pgwpMonthsLeft → 解锁 window(时间窗)结论。
接入:PlanPrView 答题态,基本 4 题已满时渲染探索卷;答完出报告(confidence → high 由引擎现有逻辑自动)。
bands 存储扩 `crsBand/pgwpBand`(localStorage 同 KEY)。

### 2.4 报告态版式(PlanPrView 重写报告分支,照 v2c 图)

五段:① hero 大数字(conclusions[0] 按 key 取数:listedHit→named/open;screenPass→open;兜底=纯文本行)
+ hint 短句;② lanes 三卡+状态章(可走/补分/对照,Resume Worded 范式);③ 免费结论两条(现有 Line 组件);
④ 下一步 1/2/3 编号行(nextSteps 渲染,尾链);⑤ 锁区=locked.map(kind → `rpt.lock.*` 标题行,🔒+Pro 章)
+ CTA 卡(文案「完整报告 + 30 天全站 Pro」+「一次付清,无自动续费」;**不写退款**;按钮 → /pricing,
价格显示交给定价页不硬编)+ hook 行(「再答 2 题可算 EE 分差与时间窗 → 继续答题」→ gotoQuiz)。
Pro 视角:锁区不渲,conclusions 全量 + 备选区照旧。
