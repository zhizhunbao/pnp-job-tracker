# L2-02 题库:每张卡一套题(全部四选一)

> 承接 [L2-01 七目标决策树](01_七目标决策树.md)。2026-07-30 Frank 定的形态:
> **每张卡有自己的问题列表 → 分基本问题与探索问题 → 全是四选一 → 答完出报告。**
> 铁律不变:每题绑定一个字段、影响至少一条结论;挂不上结论的题不入库。
> 采集控件复用 `OnboardingWizard`(E11-05)零打字点选;题库是配置(`lib/questions.ts`)。

## 0. 通用规则

- **四选一**:每题恰好 4 个选项,必含一个「不确定/都可以」类兜底,不逼用户瞎填。
- **基本问题**:4 题,答完**立刻出报告**(粗版,标 confidence)。
- **探索问题**:5-8 题,答得越多报告越细;随时可停,停在哪算哪。
- **跨卡复用**:答过的题永不再问(如「你现在的情况」全站只答一次)。
- 🔒 = 敏感题:可跳过、不外显、不进 AI 上下文,只在本地规则参与判定。

## 1. 答完之后:报告

每张卡答完(基本 4 题即可)都出**同一种结构**的报告(契约见 L2-01 §2):

```
结论(一句话) → 依据(数据 + 出处 + 日期) → 缺口(还差什么、差多少)
  → 下一步(具体动作) → 备选(换省、换岗、换专业)
```

- 只答基本 4 题:报告出粗版,`confidence` 标低,缺口行写「补 N 题可算 X」。
- 每答完一批探索题:结论变细、`confidence` 上调、缺口行变短。
- **答题与看报告是两个界面**:答题页只有题与进度,报告页只有结论与依据,互跳靠一个按钮(2026-07-30 Frank 拍板)。
