## 2. 数据基建结论(侦察已核实)

- 下架已有两径:实测判死(closed_jobs.json→closed_at)为主、30 天规则兜底(closed_at=补记)。**在架天数只按实测判死岗算**,口径注脚说明。
- `postings.json`(累积当前态)有 `datePosted` + `last_seen`,ETL 侧可全量推导新增/下架/在架天数,**不读 DB**(架构铁律:ETL 只碰 data/)。
- 唯一时序表 `stats_daily`(日×省×大类)缺下架计数 → 本批补 `closed` 列,趋势图后置。
- 趋势榜口径基于 Job Bank 全国数据(占绝对大头);ATS 不进趋势榜,口径行注明。

## 3. 派生指标与列契约(ETL ↔ 前端唯一契约,两侧不得擅改)

**修订 v2(2026-08-06 晚):实施中发现 last_seen 停更不是可靠下架信号(增量抓取不复核老帖,虚高约六成)——凡上前端的数字必须经得起「怎么算的」追问,口径改为:**

`stats_occupation`(职业×省,已有表)**加列**:

| 列 | 算法 | 上前端? |
|---|---|---|
| `new30d` | count(datePosted ∈ (T−30d, T]) | ✔ |
| `new30d_prev` | count(datePosted ∈ (T−60d, T−30d]) | 仅作分母 |
| `mom30d` | new30d/new30d_prev − 1;prev<5 时 null | ✔ 即「环比涨跌」 |
| `closed30d` | count(判死日 ∈ 窗口),源=expired_ids.json 台账(27k 条,7-25 起) | ✘ 暂不展示:判死日≠真实下架日,排水期虚高;台账稳态后(E13-04)再启用,净流失榜同步后置 |
| `avg_days_open` | avg(判死岗 closedAt − datePosted),样本<5 null | ✔ 质量已验(均值25d,零负值) |
| `pulse_score` | 0.5·z(mom30d) + 0.3·z(namedJobs/openJobs) + 0.2·z(薪资偏离) | ✔ 动量分量改用 mom30d |

- 全国行沿用既有 `province='all'`(小写,不新造 'ALL')。
- `stats_daily` 加 `closed` 列(判死日计,同上暂不展示,积累时序)。

**修订 v3(同日晚,两处数据成熟度问题):**
1. mom30d 分母窗(6-07~7-07)卡在抓取全国化爬坡期,全员假涨 +169% → **加 `mom14d` 列**(new14d/new14d_prev−1,四个窗全在 7-02 稳定覆盖后,干净),S2/S3 与 pulse_score 动量分量用 mom14d;mom30d 加成熟度闸门(分母窗触及 COVERAGE_COMPLETE=2026-07-02 之前一律 null),约 8-31 后自然解禁,届时 ETL 一行常量切回。
2. 7-25 起验尸排水清了 2.7 万死帖,存量下跌=数据清洗非市场收缩 → **S1 净值卡(存量差)后置**,与净流失榜同入 E13-04(排水稳态+干净 30 天窗,约 9 月初)。S1 三卡改为:**近 14 天新增(带环比) / 平均在架天数 / PNP 命中率**。

样本门槛(源需求 §8.2):全国榜 openJobs ≥ 30,省级 ≥ 10,城市级 ≥ 5;不足不进榜(禁上榜噪音)。粒度一律具体职业(NOC 细类),不用大类。

**DB 加列走 docs/sql 手写(铁律:禁 DB_PUSH 推)** + seed 白名单 dims[] 同步补映射(老坑 #2)。
