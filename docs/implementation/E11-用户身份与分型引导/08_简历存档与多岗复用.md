# E11-08 · 简历存档与多岗复用(G3 §3b,2026-08-03 Frank「按你的建议来」立项;2026-08-04 施工)

> 上游 [E11-07 简历上传解析](07_简历上传解析.md)(解析器 `lib/resumeExtract`,原件不落盘)。
> 主线判据:求职副驾「简历环」的复用地基 —— 每个岗重传一遍是 G3 上线后最直接的摩擦。

## 1 · 目标

简历文本**存进用户档案**(默认不存,用户点了才存),弹框打开即预填、一键对照;账户页能看能删;隐私页同步口径。

**红线**(不上砧板):
- 默认不存 —— 勾选框默认关,不勾=行为与今天完全一致(内存比完即弃);
- 能看能删是能存的前提 —— 账户页入口与存同批上线,不许先存后补;
- 原件(PDF/DOCX 二进制)照旧不落盘,只存抽出来的**文本**;
- LLM 日志照旧只记长度与耗时,不记内容。

## 2 · 链路与契约

```
弹框打开(loggedIn) → GET /api/users/me → profile.resumeText 有值 → 预填 textarea + 小注「用的是存档 · 清除」
上传/粘贴 → 勾「存进档案,下次直接用」(默认关)
→ POST /api/resume-match { jobId, jd, resume, lang, save:true } → 对照成功后顺带写档案(一次往返,不新增端点)
账户页「档案」节 → 显示 存档时间 + 字符数 + 展开查看 → 「清除」 → PATCH /api/users/:id { profile:{ resumeText:null, resumeSavedAt:null } }
```

**存哪**(验证推翻了立项时的「零新列」前提):`users.profile` 是 Payload `type:'group'`,
在 postgres 里**展平成 7 个 `profile_*` 列**,不是一个 jsonb —— 未声明的键被 drizzle 静默丢弃
(证据见 §3 ①)。所以按 [[db-push-minefield]] 惯例走 `docs/sql/` 手写 DDL:

| Payload 字段 | 列 | 类型 | 用途 |
|---|---|---|---|
| `profile.resumeText` | `profile_resume_text` | `varchar` | 简历文本,上限 20,000 字符(服务端截断) |
| `profile.resumeSavedAt` | `profile_resume_saved_at` | `timestamptz` | 存档时刻(账户页显示 + 用户判断新旧) |
| `profile.matchUses` | `profile_match_uses` | `varchar` | 日限计数 `"YYYY-MM-DD:N"` —— **修 §3 ① 的死闸** |

## 3 · 施工前抓到的两条(本批一并修)

- **① 免费日限闸门在生产上一直是失效的**(本批第一发现):`resume-match/route.ts:77` 往
  `profile.matchUses` 写计数,而该键**从未在 collection 声明** → `@payloadcms/drizzle` 的
  `traverseFields` 按 schema 声明的字段去 data 里取值(不是遍历 data 的键),多余键静默丢弃、不报错
  (路由那句还裹着吞异常的 catch)。后果:读回恒 `undefined` → `used` 恒 0 → **非 Pro 每天可无限调用**,
  返回给前端的 `left` 恒等于 `DAILY_FREE-1`。三条独立证据:列不存在 / 全库 11 个 json 列扫 `matchUses` 命中 0 /
  适配器源码。**教训与 [[new-etl-dim-table-checklist]] 同源:Payload 侧不声明 = 数据不存在,而且不报错。**
- **② 整组覆盖是个哑雷**:`data:{ profile:{ ...prof, matchUses } }` 靠 `...prof` 保住其余字段。
  今天安全(`getUser` 走 `payload.auth` 返回完整 user,不裁字段),但任何一次给 `getUser` 加 select
  都会**顺手清空用户档案**。本批收进 `lib/profile.ts` 的 `patchProfile(userId, patch)`,调用点不再自己拼整组。

## 4 · 隐私口径(必须与实际行为一致)

隐私页(`legal/privacy/page.tsx`,三语硬编码)当前**一个字没提简历**。本批补两句:
- 存:简历文本仅在你勾选后存入你的账户,账户页可随时查看与清除;原件不保存;
- 送:简历对照会把简历与职位描述文本发给本站使用的大模型服务做比对,不用于训练。

> ⚠️ **通道口径(2026-08-04 Frank 拍:「不用换回」)**:`resume-match` 定向走 `provider:'friend'`
