## 1. 整体目标

雇主线索从「只长在报告卡①」变成有自己的货架且两头互通;免费=浏览/筛选/计数(B2 现状不动),
付费=**按筛选导出的名单文件** + 报告卡①↔货架双向接线;定价页第一卖点(price.pA 担保雇主名单)配真图。

## 2. 方案与口径

- **免费层不动**:/employers 浏览、四凭证筛、省/职业筛、计数全免费(companyResearch 懒查询照旧)。
- **付费层=导出**:`/api/employers-export`(GET,参数与页面同款 f/prov/noc/q/sort)→ 按当前筛选出全量
  CSV(UTF-8 BOM,列=雇主/AIP/LMIA 岗数/技能类/最近季度/PNP 紧缺/在招/省/市)。**Pro 才 200**,
  免费/匿名 402;前端免费态点「导出名单 CSV」→ `/pricing?from=se-export`(沿用 ?from= 漏斗口径)。
- **个人化**:档案有 `nocCodes/targetProvinces` 时页面出「按我的档案筛」chip → 一键带 noc+prov 刷新
  (匿名/无档案不出,不硬引导)。
- **报告卡①互通**:雇主线索节尾加「在担保雇主页看全部 →」→ `/employers?noc=<报告 noc>`;
  免费报告(employers 服务端清空)也出此链——货架本身免费,锁区卖的仍是「匹配到你+雇主门槛落到这一家」。
- **定价页素材**:/pricing 副标下挂 B2 页真图(zh/en 双资产,ko 用 en;webp 压缩入 cms/public),
  点图落 /employers;PricingCard(弹窗共用)不动,只改页面壳。
- **收藏后置**(蓝图列了但本批不做):要新表(雇主收藏)= schema+payload_locked 六步,先拿导出读数,
  有点击量再立项——判据同主线:先证明有人要这份名单。
