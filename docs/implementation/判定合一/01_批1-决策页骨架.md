## 3 · 决策页结构(/plan/pr,SSR + 客户端岛)

```
page.tsx(服务端):取 profile + score-factors + draws + streams + requirements 概览 + 热门职业
└─ PrDecisionView(客户端):
   ├─ H1 + 一句说明(SSR 可见)
   ├─ 各省通道概览表(SSR 可见;pnp_requirements 摘要行 + 最近抽选分/日期)
   ├─ 答题区:OccPicker + QuizForm(decision='pr')→ 完成即 quizToProfile + 展开下方
   ├─ 分值卡 PnpScoreCard(factors 有数据才渲,同 pathways 现行为)
   ├─ 三关判定:?job= 有 → TripleVerdictModal 自动开;无 → 占位卡(去职位板挑岗)
   └─ 出口三钩子:看在招岗(?noc=)/ 跨省对照 / 问顾问(o2p:chat-open)
```

版式铁律:PageShell 1320 套壳、右上 goBackOr 返回、H1+白卡、JobsTable 形态卡、手机 375 先验、
禁「·」、文案四闸、代码不裸奔(省全名+灰字代码)。
