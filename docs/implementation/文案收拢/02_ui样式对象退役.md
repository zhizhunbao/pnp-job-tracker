## 1 · 背景与范围

上一轮 381 处内联样式迁完后剩 32 处「站得住」的,其中一批的成因不是「真动态」,
而是**被四个 ui 侧样式对象挡住**:`{...ctrl, paddingRight:38}` 这种要盖掉对象自带的值,
搬进类会被内联盖回去。所以这是**结构问题不是 CSS 问题** —— 先决定这四样还要不要以
「样式对象」形式存在,再谈迁移。

### Frank 两次拍板

| 决策 | 拍板 |
|---|---|
| 形态 | **全变成类,加料留内联** |
| `ctrl` 改名 | **`field`** |

### 判据(实测,不是印象)

「留对象」的唯一好处就是能展开加料。实测加料率:

| 对象 | 纯 `style={OBJ}` | 展开加料 | 加的是什么 |
|---|---|---|---|
| `CARD_MD` | 21 | 1 | 字号/行高/颜色 |
| `link` | 8 | 0 | — |
| `PILL_BTN` | 7 | 0 | — |
| `CARD_SHELL` | 3 | 5 | padding / position / margin / maxWidth |
| `ctrl` | 3 | 5 | display / visibility / paddingRight / 几何 |

加的全是**「这一处的几何」**,照上一轮的手法留内联即可(内联盖类,方向对了)。

### `ctrl` 为什么必须改名

全站 60 处 `ctrl` 里**大多数根本不是这个样式对象** —— 是 `AbortController` 局部变量
(`ctrl.abort()` 11 处、`ctrl.signal.aborted` 11 处、`ctrl.signal` 8 处)。
这个名字既说不出装什么(违反 CLAUDE.md「名字说装什么」),又和一个通用局部变量名撞车。

## 2 · 落地

### 2.1 五个类,放**早段**

- `.field` / `.pill` / `.link` → main.css **第 5 段**(控件基准值)
- `.card` / `.cardMd` → main.css **第 9 段**(卡片 Card)

**位置是设计的一部分**:它们原先是内联的、压过一切;变成类之后必须让下面的组件段
(第 14/15/16/17/18 段)能自然覆写。直接的收获是 **`.advPillOff` 的 `!important` 撤掉了** ——
先前 `cursor:default` 得靠它才压得过 `PILL_BTN` 内联进来的 `pointer`,现在按源序就赢。

第 9 段的段头注释里那句「**未迁**:CARD_SHELL / CARD_MD…留给下一批」也一并改成已迁 ——
它就是给这一批留的话。

### 2.2 占类名前先 grep(上一轮的教训,这次又救了一次)

`.link` 被 `.jdPill.link` 这个**修饰类**占着(与上一轮 `.row` 撞 `.jtBtn38.row` 同款)。
裸 `.link` 一旦成立,`<a className="jdPill link">` 会连带吃到蓝链的 `color`,是实打实的回归。
**让位的是修饰类**:`.jdPill.link` → `.jdPill.asLink`(1 条 CSS + 1 个调用点)。

### 2.3 Jobs.tsx 的胶囊改「语义色名」

病:每种胶囊的配色是**固定语义**(可提名=琥珀、不受理=红、EE=蓝、试点=天蓝…),
却在 12 个调用点传裸 hex,还得靠一张 `bg → border` 查表把第三个色补出来 ——
**同一种胶囊的三个色值散在两处**,改一种颜色要动三个地方。

改法:`chip(tone, …)` + main.css 里一个 tone 一条规则(`.jtChip.tone-amber { --cbg/--cfg/--cbd }`)。
**Jobs.tsx 里的 hex 从 24 个降到 4 个**(剩下的 4 个是别处的真动态值)。

### 2.4 codemod 与三种手工

脚本处理两种规整形态(`style={OBJ}` → `className`;`style={{...OBJ, 几何}}` →
`className` + 只留几何的内联),58 处 / 11 个文件。剩下三类脚本不猜、逐个点名:

- **本地别名**(`const CARD = CARD_MD` / `const btn = PILL_BTN` / `const sec = CARD_MD`)—— 4 处
- **派生对象**(`const card = {...CARD_SHELL, padding}`)—— 2 处
- **条件用**(`const wrapSty = flat ? undefined : CARD_MD`)—— 1 处,改成 `flat ? 'flatSec' : 'cardMd'`

顺带删掉 `employers/Employers.tsx` 里**自己抄的那份 `ctrl`**(与 ui 的逐字符相同)。

### 2.5 ⚠️ 多行 JSX 的坑(tsc 抓住了)

codemod 的「并进已有 className」只往**同一行**回看 `<`,遇到多行 JSX 元素时
(className 在上一行)就以为没有,新插了一个 → **同一个标签两个 className**。
所幸 `TS17001`(JSX 元素不能有同名属性)直接报错,2 处全被抓住。
**教训:codemod 改 JSX 属性,别按行处理。** 这次靠编译器兜住了,不能指望下次也这么巧。
