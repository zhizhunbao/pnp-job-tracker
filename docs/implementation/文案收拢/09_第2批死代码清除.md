## 5 · 留下的账

### 🔴 `pw.*` 文案:一半活一半没了产出方,**没删**

`report.ts` 里 `pw.` 出现 **162 处**(三语)。其中**通道名那部分**(`pathwayNames`)还活着;
当年由 `pathwayRecipes.ts` 产出的那批(`pw.steps` / `pw.gaps` / `pw.forYou` 等,旧 `/pathways` 方案卡的正文)
随该文件一起没了产出方。

**不删的理由**:这些键是 `t(key, params)` **动态拼**出来的,tsc 和 eslint 都证不了死 ——
猜错的代价是页面上冒一个裸键。要人对着页面核一遍再动。文件头已就地写明。

### `db/database.ts` 现在只剩「取池」

`select` / `selectOne` / `selectValue` / `execute` / `insertMany` / `withTransaction` / `dbOrNull` 全删之后,
它只剩 `poolOf` / `dbOf` / `getDb` 与三个类型。**这说明「通用 CRUD 门面」这层从来没被采纳** ——
域文件一律直接 `pool.query(SQL.x)`(`directory.ts` 就是样板)。
📌 记忆 `db-layer-shape` 里「database.ts 通用 CRUD」那句要按现实改。

### `/employers` 的读函数没了

`fetchAipEmployers` / `fetchLmiaEmployers` 删除,`/employers` 的数据走 `employers/board.ts`(tsc 已证零引用)。
**上线后实测这两页**(`/employers`、`/occupations`)。
