# E12-09 · 省提名分数参考与「换省/换岗」建议

> 立项 2026-07-26（Frank 走查原话：「安省和 BC 省现在打分，需要有一个参考，**如果用户觉得自己分不够
> 赶紧换省 换工作，不要继续耗**，这也是最大的价值」）。
> 本站已有的是「这个岗能不能提名」；缺的是「**你这个人现在够不够分、不够该换去哪**」。

## 1. 整体目标

给用户一个**可对照的分数参考**：目标省的打分构成 + 近期抽选分数线 + 自己大致落在哪 → 结论是
「继续等」还是「换省 / 换岗 / 换城市」。不做资格认定，只做**基于官方公开分数表与官方抽选记录**的对照。

## 2. 验收标准

- [ ] BC：SIRS 打分表（各因素分值）落库，用户自评几项即得估分；与 BC 近期抽选线（已在库 `pnp_draws`）对照
- [ ] ON：现行 Workforce Priority 的 EOI 打分因素落库；**官方 EOI 系统未开放前，页面必须明说「尚无分数线可比」**
- [x] 给出「差多少分」与**可操作的三条路**(现已给:差分 + 换省该省 offer 加多少分 + 该省同职业在招数)：换省（哪些省用同一职业分更够）、换岗（同职业更高薪/更偏远的岗位）、补短板（语言/学历，只列官方分值不指导考试）
- [ ] 每条结论挂官方出处链接；无官方分数表的省**不出现估分**，只给抽选线事实

## 5. 红线与坑

- **自评分 ≠ 官方分**：官方以文件审核为准，页面必须写清是「按官方分值表自算」。
- **ON 的分数线不能拿来对照(2026-07-31 落地时按这条实现)**:官方 invitations 页确实逐轮公布分数区间,
  但那些轮次属于**改制前已关停的通道**(Employer Job Offer 各流、Masters/PhD Graduate),
  与新 Workforce Priority 通道的 130 分制不是同一套分制。做法:打分表的 `system` 自报通道名
  (`OINP EOI points (Ontario Workforce Priority stream)`),显示层只认**同一条通道**的抽选;
  对不上就明说「这条通道还没有抽选记录」,不含糊说成「官方未公布」。
  新通道开始抽选后,近 N 次窗口会自然换成新数据,不需要改代码。
- **换省建议只能基于事实**：该省在招数、该省分数线、该省是否有该职业清单；不得编造「更容易」。
- 官方分数表改版频繁 → 分值表必须带 `fetched` 与官方链接，过期宁可不显示。
