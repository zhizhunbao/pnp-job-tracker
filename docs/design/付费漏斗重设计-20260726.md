# 付费漏斗重设计：注册 → 建档 → 付费（2026-07-26 立项）

> Frank：「我不应该重新设计一下付费方式么，怎么引导用户，注册、填内容、然后付费」。
> 本文件设计的是**路径**，不是功能清单。路径设计不需要流量，现在就能定死；
> 转化率的验证等量上来（见 [冷启动获客与首笔付费](冷启动获客与首笔付费-20260726.md)）。
> 一句话主张：**从「解锁功能」改成「卖一份结论」——先给结果，再要身份，最后卖深度。**

## 1. 现状漏斗（2026-07-26 实测，每层都是真数）

| 层 | 现状 | 实测 | 断点诊断 |
|---|---|---|---|
| 到站 | 内容/搜索 → **34% 落在首页** | 窗口内真实外部访客约 20-30 人 | 落到 4 万条列表上，自己找不到与自己相关的东西 |
| 注册 | 闸在「锁列」「投递」处 | 22 天 15 人 = 0.7/天 | 闸太早：还没看到价值就被要账号 |
| 建档 | 注册后向导（分型 + NOC + 语言 + 目标省） | **6/15 = 40%** | 只说「建档案」，没说「填完你能看到什么」 |
| 留存 | 收藏 / 保存筛选 / 周报 | 收藏 9 次、**保存筛选 0 次** | 保存筛选没人用，却还在当付费卖点 |
| 付费 | 限额型：AI 次数、保存位、匹配列 | **真实付费 0**（两条 session 一条测试号、一条自己退款演练） | 用户看不出多花 $19 换到什么；定价页还在卖已免费的功能 |

**结论**：断点不在「功能不够」，在**「没有一个时刻，用户清楚地知道自己在买什么」**。

## 2. 三条设计原则

1. **先给结果再要身份**：任何人不登录就能看到「这批岗里哪些能走移民」。注册闸只挡「**我**能不能走」。
2. **卖交付物，不卖次数**：付费买到的必须是一个**能拿走的东西**（一份清单、一份对比、一封能发的邮件），
   不是「AI 多用 180 次」。次数是成本，不是价值。
3. **付费点长在决策时刻**：人愿意掏钱是在「要投了 / 要选省了 / 要判断这家公司靠不靠谱」的那一秒，
   不是在浏览列表的时候。

## 3. 新漏斗（Frank 2026-07-26 拍板：**入口即问**）

> Frank：「用户一访问页面就应该弹出一些问题，吸引用户填，然后最终拿结果付费」。
> 采纳。这比「先浏览后建档」更适合本站：三题答完用户已投入，注册与付费意愿都跳一级。
> 效果图：[entry-quiz-20260726.png](../assets/mockups/entry-quiz-20260726.png)（数字全为库内真数）

**四步：问 → 免费结果 → 注册保存 → 付费清单**

| 步 | 屏 | 要什么 | 用户为什么继续 |
|---|---|---|---|
| 1 | 落地即弹底部抽屉，**三题、每题一屏、可跳过** | ①你在哪一步（境外/留学/在加工作/已有 offer）②你做什么工作（搜索 + 常见项）③目标省（多选，可选「都行」） | 首屏就说清「答完直接告诉你：你的职业在哪些省能走移民」 |
| 2 | **免费结果页**（不要求注册，立刻出） | 无 | 拿到别处查不到的真数：本职业在招数、可提名数、命中哪张省具名清单、按省分布、中位薪资 |
| 3 | 「先免费注册，保存这次结果」 | 邮箱/Google | 结果会随岗位每天变；注册后进周报、可保存 | 
| 4 | 付费卡：**这 N 个可提名岗里，本周该投哪 20 个** | CA$19 | 免费给了「有多少」，付费买「投哪些、为什么、怎么写信」 |

**硬约束**（否则弹窗会变成拦路虎）：
- 三题封顶，每题一屏，进度条可见；「先随便看看 ×」永远在；只弹一次（localStorage 记）。
- 答完**立刻**出结果，不许转圈等 AI —— 结果来自库内聚合查询（毫秒级），AI 只在付费包里用。
- 跳过的人照常进职位板，不再骚扰。
- 匿名答案存 localStorage，注册后落库成档案（不让用户填两遍）。

## 3b. 原漏斗（供对照，已被 3 取代）

| 层 | 用户看到 | 我们要什么 | 用户为什么往下走 |
|---|---|---|---|
| **L0 到站** | 内容对应的**具体页面**（某职业 / 某省 / 某政策），首屏一句结论 + 真数字 | 什么都不要 | 一眼看到「这事跟我有关」 |
| **L1 免费结果** | 这批岗里**哪些可提名、哪些命中省具名清单、哪些雇主有担保记录** | 什么都不要 | 这是别处查不到的，先建立「这站有真东西」 |
| **L2 身份钩子** | 「想知道**你**能不能走？两分钟建档」 | 注册 + 3 个问题（职业、语言、目标省） | 从「这批岗」变成「我的岗」，价值跳一级 |
| **L3 免费个人化** | 与我匹配的岗 + 每条一句依据（为什么算你能走） | 无 | 免费给足，形成回访 |
| **L4 付费触发** | 决策时刻弹出：**买一份可执行的结论** | CA$19 | 省掉自己翻 40,981 个岗、10 个省口径的几十小时 |
| **L5 复购** | 一次性包，用完再买；每周邮件带新一期 | 再 CA$19 | 岗位每天变，结论会过期 |

**关键改动 vs 现状**：注册闸从 L1（锁列/投递）后移到 L2；建档从「表单」改成「三问 + 立刻出结果」；
Pro 列（`PRO_COLUMNS` 现只剩 `match`，名存实亡）**退役**，付费面改成交付包。

## 4. 付费产品定义（二选一先做，不要都做）

### 方案 A · 投递清单包 · CA$19
**交付**：按你的档案，从当前 40,981 个在招岗里挑出**本周最值得投的 20 个**，每个岗给：
- 一句「为什么是你能走的」（命中哪条通道 / 哪张省清单 / TEER 与语言够不够）
- 雇主担保记录摘要（LMIA 获批职位数与季度，没有就明说没有）
- 一封可直接发的求职邮件初稿（中英双版，措辞过红线：不承诺、不代办）

**触发点**：匹配视图顶部、投递弹框里、每周邮件。
**为什么值 19 块**：用户自己做这件事要翻几十个岗 × 各省口径，几小时起；顾问收费 $200+ 起。

### 方案 B · 省份决策包 · CA$19
**交付**：你的职业在 10 个省的可行性对比表 —— 每省给：清单命中与否、最近抽选线、工签/学签存量、
竞争比与难度档、当前在招岗数、结论一句话（建议 / 不建议 / 有条件）。
**触发点**：/stats 跨省对比、档案里选目标省时、pathways 页。
**为什么值 19 块**：选错省=浪费一年。这是一次性的重大决策，且数据全在站里现成。

**我的建议：先做 A**。理由：A 的触发点在「要投了」，离掏钱最近；B 更像一次性咨询，复购弱。

## 5. 要改什么（代码侧，按顺序）

1. **定价页修谎**（十分钟）：「工资中位对比」已免费却还列为 Pro 卖点。
2. **注册闸后移**：锁列改成「免费看结论，建档看你自己的」；投递闸保留（投递本就要账号）。
3. **建档三问化**：现向导按分型分支多步，砍到「职业 / 语言 / 目标省」三题 + 可跳过，填完**立刻**出匹配结果。
4. **付费面替换**：`PRO_COLUMNS` 退役 → 新增交付包（生成 + 交付页 + Stripe 一次性 $19 复用现有 checkout）。
5. **定价页重写**：从「功能对比表」改成「你买到的是这份东西」+ 一份**真实样例**（脱敏）。

## 6. 硬核内容选题（回应「本周新增 top 不够硬核」）

榜单罗列不是钩子。钩子=**别处查不到的事实 + 一个能立刻用的结论**。以下每条都有真数锚（2026-07-26 库内实测）：

| 选题 | 硬核在哪 | 真数锚 |
|---|---|---|
| 「TEER 4/5 也能移民」 | 打破「低学历没戏」的普遍误解 | 低门槛可提名岗 **4,761 个**（餐饮 490、零售 459、照护 383、文员 358、护理员 300、清洁 291） |
| 「雇过外国人的公司现在在招什么」 | LMIA 获批记录=历史事实，官方表格没人愿意翻 | 有 LMIA 记录雇主 **4,465 家** |
| 「NB 突然不受理这些职业了」 | 政策变化 + 影响面 | NB 可提名 **1,011 → 635**，餐馆厨师/零售/食品加工被排除 |
| 「安省改制后全职业可提名」 | 大政策，多数人还不知道 | ON 可提名 **6,743 → 10,039**（+3,296 全是 TEER4-5） |
| 「BC 新政的 46 个医疗职业」 | 具名清单，直接对号入座 | BC 清单命中 **999 个在招岗** |
| 「命中省具名清单的岗只有 6%」 | 反直觉的稀缺性 | 2,572 / 40,981 |
| 「大西洋四省 AIP 指定雇主在招 729 个岗」 | AIP 门槛低但没人知道去哪找 | 729 |
| 「联邦 EE 类别抽选覆盖 8,736 个在招岗」 | 把抽选类别落到具体岗位 | 8,736 |
| 「一周新增 10,018 个岗，其中可提名的有多少」 | 日更规模本身就是硬实力 | 近 7 天新增 10,018 |

**统一结构**：一个反直觉事实 → 一张真实数据截图（站内页面）→ 一句「你该怎么用」→ 落地页深链。

## 7. 验收

- [ ] 定价页无假卖点（与 `plan.ts` 逐条对齐）

- [ ] 付费包上线：生成 → 交付页 → $19 一次性；定价页给出真实样例
- [ ] 首个付费用户（非测试号、非退款演练）

## 8. 不做什么

- 不做订阅制（一次性交付包与本站「结论会过期」的性质更配，也避免退订摩擦）。
- 不在包里承诺 offer / 移民结果——红线：本站给信号与依据，不做资格认定。
- 不在 200 真实用户之前反复调价（样本不够，改了测不出）。
