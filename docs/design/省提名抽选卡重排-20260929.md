## 二、判据

1. **一张卡只讲一件事**:一个项目(省提名 / AIP)、一个时期(改制前 / 改制后)。
2. **卡里列的加起来 = 卡上写的合计**:抽选卡只列今年,卡底合计行的份数 = 配额卡「已邀请」,同一个数只在汇装算一次(invitations_ytd),前端只显示。
3. **没有就标上**:SK 不抽选、AIP 没数据,都出卡写明,不静默缺卡。
4. **九省同一套骨架**,不给某省单独设计;省与省的不同只在数据。

## 四、数据层

1. **AB / BC 小批次原文**:官方人数格写「Less than 10」(alberta.ca/aaip-processing-information)、「<5」(welcomebc.ca 邀请页),
   现在 pnp 域解析成空。改为留原文进新键,mart 抽选表带出,DB pnp_draws 加一列(docs/sql 手写 DDL 先行)。
2. **「至少」合计**:汇装对「今年有原文轮次」的省另出一行下限(已知人数合计,label 记几轮只有原文),现规则「缺一轮整省不出」只对真缺(空、日期认不出)保留。

4. **ON 旧通道直白名**:通道对照表补 In-Demand Skills / Masters Graduate / PhD Graduate 三条已关闭通道(现只登了两条),改制前卡的组下灰字要用。
