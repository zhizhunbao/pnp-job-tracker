# 雇主板重构 —— 一块板、身份定视角、星级机会档(2026-08-30)

> 本文收拢 2026-08-29/30 夜 Frank 逐条拍板的雇主板需求。效果图豁免(Frank:「CSS 都是固定的,主要是包含哪些信息、怎么交互」)。
> 分三批执行:批一数据层(雇主池)→ 批二展示层(板收敛)→ 批三盯钮。改错层下游白干,顺序不许倒。

---

## 1. 定位(Frank 拍板的产品判断)

- **用户只有一个问题:「谁最可能要我」。** 翻盘用户(分数不够、要靠 offer/地方通道)是本板客户;高分人群走 EE 大道,不是这页的客户。有医疗背景的走 EE 定向抽签,也不是。
- **岗与雇主是两个时间尺度**:岗短周期(职位板管),雇主长周期(担保资格、雇外国人历史、常年缺人模式)。本板的主语是**雇主**,服务「圈定目标雇主、一家家经营」的主动打法;试点社区名录几十家 = 机会全集 = 作战地图。
- **主力盘身份牌面 = 开放工签(留学 PGWP)+ 旅转工**。PGWP 用户任何雇主零成本可雇 —— 在招才是命门;旅转工 LMIA 是命门(少数);试点区名录是硬门槛。
- 「哪个要你去哪」:大类内工作大同小异,**比较单位是雇主不是岗**;板不做「帮你挑工作」,只做「谁最可能要你」。
- **刚毕业痛点**:大部分岗要经验 —— 经验门槛字段(experience_levels 现成)聚成雇主级「无经验可投」信号。
- 功能完全基于能抓到的数据(Frank 总纲):本板**零新抓取**,纯三源(jobs/designated/lmia)聚合。

## 3. 批一:数据层 —— 雇主池 mart 表

**一行 = 一雇主**,大类相关列按 **雇主×大类** 分桶存(一家最多 17 桶)。

| 列组 | 字段 | 来源 |
|---|---|---|
| 身份 | 名称、行业、省、市 | 三源归一 |
| 在招(分桶) | 岗数、最新发布日、主要职业名 | jobs |
| 门槛(分桶) | 无经验岗数与占比、最低经验档 | experience_levels |
| 证据(分桶) | 技能类 LMIA 获批(份数+最近季) | build_lmia 按大类归桶 |
| 证据(全局) | 指定雇主归属+项目(AIP/RCIP/FCIP) | designated_employers |
| 星级(分桶) | 1-5 档,口径见拍板 #6 | etl 评分层算死 |
| 规模代理 | 历史累计岗数(含 closed)、运营省市数、wikidata 命中 | jobs+closed_jobs+employers 域对齐 |
| 价值 | 工资水位 vs 行业中位 | 08 评分既有口径 |

- 脏活归 `etl/clean/`:公司名跨三源归一(复用 companies 既有逻辑,残差留空不硬合)、经验档归一。
- 星级评分住 etl(08 系),排序键不在前端算(拍板 #12)。
- DB 走 `docs/sql/` DDL 先行 + payload_locked_documents_rels 补列六步。
- 池表构建落单源事实表惯例(build_employer_pool 类),自成整块,配合日后 etl 分域重构可整体搬迁。

## 4. 批二:展示层 —— 一块板五个态

- **① 首屏态**:职业大类选择器 + 省选择器 + 搜索框,不摊表。
- **② 榜态**:默认按星级排;开关三个:**只看在招 / 只看指定雇主 / 无经验可投**;榜头摆该大类职业胶囊(号脉用,非筛选器);375 表转卡。
- **③ 行内**:七格 = 雇主名+行业 / 地点 / 星级 / 在招(岗数,无经验占比灰注)/ 证据(指定徽章+技能类 LMIA)/ 工资水位 / 动作(看岗位→带公司筛选落职位板;盯这家→注册闸)。点行进 `/companies/[slug]`。
- **④ 查证态**:搜索框有输入即全库搜(不受筛选约束);命中摆证据;未命中:「不在官方指定雇主清单内,警惕任何承诺担保的说法」(≠资格认定族)。
- **⑤ 空结果态**:放宽引导一键改筛选(换省/看全国)。
- **身份预置 = 全部智能**(零新判定逻辑,读现成身份档案选开关):毕业一年内+无加国经验 → 「无经验可投」默认开;旅转工画像 → LMIA 筛选/主键升格;`noc=`/`program=` 直达参数照旧预置。
- 旧路由:`/employers/hiring` 301+「只看在招」开;`/employers/designated` 301+「只看指定雇主」开。
- Banner 戴帽照抄 jobs.tsx 的形。
- 详情页补三块:官方背书层级、招聘模式(当前岗+历史常招+规模代理)、按通道核对雇主(判据类核对清单,#11)。

## 5. 批三:盯钮

钮+注册闸+订阅落库;提醒推送(邮件/站内)另立批。

## 6. 不做 / 边界

- 不做全局机会榜(农业/医疗水量必然霸榜 —— LMIA 排行实拍为证);所有信号只在「大类×省」切面内呈现。
- 不编雇员数/营业额;不标「正规」;不拿裸 LMIA 总量排序。
- 雇主侧判据(OINP 类)不入列,只做核对清单。
- 星级是机会参考,不是资格认定,文案挂死。
