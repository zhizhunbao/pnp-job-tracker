# 方案：从 15 个真实用户到第一笔付费（2026-07-26 立项）

> 起因：Frank 问「为什么没人付费」。查了生产库与 Umami，结论是**人太少，还轮不到谈付费**。
> 本文件是给这个问题的完整方案：先解决量，同时把「接住人」和「收钱」的路铺好。
> 本方案不改产品功能顺序，不与整改轮次冲突；轮次照旧走 dd。

## 1. 现状（2026-07-26 实测，不是估算）

| 事实 | 数字 | 来源 |
|---|---|---|
| 真实注册用户 | **15**（另 22 个 @test.local 是我们自己的测试号） | 生产库 users |
| 真实注册节奏 | 22 天 15 人 = **0.7 人/天** | users.created_at |
| 单日最高 | **07-25 一天 8 人**（占全部真实用户一半），当天发过内容 | 同上 |
| 建档率 | 6/15 = 40% | profile_updated_at |
| 收藏 / 保存筛选 | 9 次 / **0 次** | saved_jobs / saved_searches |
| 真实付费 | **0**（库里两条 Stripe session：一条测试号 `cs_test_`，一条 Frank 07-04 的 `cs_live_` 开闸演练，已退款） | users.stripe_sessions |
| 流量来源 | google.com 82%、bing 3%、linkedin 1% | Umami |
| 落地分布 | 首页 34%，其余散在职位详情、/news、/pathways、/rankings | Umami |

**算一笔账**：这类 C 端工具「注册 → 付费」乐观按 2% 算，15 × 2% = **0.3 人**。
即：**产品和定价都完全正确，现在的期望付费人数也不到 1 个**。0 付费落在统计噪声内，
它不是产品判决书。真正的瓶颈是**没有人**，而且来的人（自然搜索查资料的）本来就不是买家。

**唯一已被验证有效的动作**：07-25 发内容 → 当天 8 个真实注册。这是本站至今最强的获客证据。

## 2. 目标与判据（可证伪，不许含糊）

| 时点 | 目标 | 不达标时的结论 |
|---|---|---|
| 第 4 周末 | 真实注册 **≥ 3 人/天**（累计 ~90） | 渠道/内容形式不对 → 换内容形式，**不动产品** |
| 第 8 周末 | 真实注册 **≥ 8 人/天**（累计 ~250）、建档率 ≥ 55% | 接得住但拉不来 → 加渠道 |
| 累计真实用户 ≥ 200 且付费仍 = 0 | 这时才允许判定「产品/定价有问题」 | 才动付费面与定价 |

**在累计 200 真实用户之前，不调价、不加付费功能、不重做付费墙。** 样本不够，改了也测不出。

## 3. 方案三段

### A · 搞人（唯一优先级）

把 07-25 那次偶发动作变成**固定节奏**。素材全部来自站内已有真数据，不新建数据源。

| 频次 | 选题 | 素材来源（站内现成） | 落地页（带 UTM） |
|---|---|---|---|
| 周一 | 「本周新增 TOP 50」精选 5 条 | `/rankings/weekly-top` | 同榜单页 |
| 周三 | 单职业/单省专题（如厨师类、BC 建筑技工） | `/rankings/daily-top` + PNP 清单命中 | 对应筛选深链 |
| 周五 | 本周政策变化速读 | `/news` 已抓 IRCC/各省公告 | 对应新闻详情 |

- 平台优先级：**小红书 > 抖音 > 一亩三分地 > 视频号**（07-24 厨师篇四平台已跑通，管线在 `short-video-studio`）。
- 分工：**我做**选题 → 拉数 → 出图/短视频 → 文案 → storyline；**Frank 做**扫码登录、拖文件、点发布（约 10 分钟/条，平台规则如此）。
- 铁律：内容里的每个数字都必须能在站上点开验证（真实数据是本站的命）。

### B · 接住人（现在的漏点）

1. **落地页不能是首页**：每条内容配对应榜单/筛选深链，首屏就给结论（这个职业本周多少岗、多少可提名），
   再引导建档。现在首页占 34% 落地，等于把人扔进 4 万条列表里自己找。
2. **建档率 40% 要提到 55%**：建档是体验到差异化（匹配、依据链）的唯一门槛，没建档的人根本没看到产品价值。
   动作=落地页首屏加一句「两分钟建档，看这批岗里哪些你能走」。
3. **保存筛选 0 次**说明这个功能没人用——不要再把它当付费卖点（现在定价页还在卖「保存 5 个」）。

### C · 收钱（先修谎，再改形态；改形态要等到 200 用户）

1. **立刻修**：定价页把「工资中位对比」列为 Pro 卖点，但 07-25 已放开免费。**页面在骗人**，与「自家文案不许撒谎」冲突，十分钟能改。
2. **立刻上**：埋点（#129，07-25 已立项未做）。没有用量数据，就没法知道该给哪个功能加 Pro——
   这是 Frank 自己拍的路线，现在两头空：既没收到钱，也没拿到数据。
3. **等 200 用户后再动**：付费面从「限额型」（次数、位数）改成「结果型」，候选两条，届时二选一：
   - **投递清单包 $19**：按你的档案，本周最值得投的 20 个岗 + 每岗一句为什么 + 可直接发的邮件话术，买完即交付。
   - **雇主尽调包 $19**：指定雇主的 LMIA 记录 + 在招量 + 清单命中 + 直投口，一次一家。

## 5. 只看四个数（每周一份，我出）

真实注册数（排除 @test.local）· 建档率 · 7 日回访率 · 付费数。
其余一律不看——避免用「曝光量」这种自我安慰指标替代真相。

## 6. 不做什么（诚实划界）

- 不投付费广告（现在没有可回收的 LTV，烧钱验证不出东西）。
- 不刷量、不买粉。
- 不在文案里承诺「拿到 offer / 保证移民」——红线，本站是信号不是资格认定。
- 不因为「没人付费」就加功能。功能不是没人付费的原因，没人才是。
