## 故事一:小李,考前三周,每天刷 20 题

**他是谁**:PGWP 在手,省提名要 CLB 7,PTE Core 报了三周后的场。白天上班,晚上刷题;小枫叶 VIP 到期了不想再交,机经在几个群里零散抄。

**他的痛**:三家平台题库各不同,不知道刷哪些;题太多刷不完,想知道**最近真考过的先刷**。

**他怎么用**:
1. 打开 `/pte`,顶部四个题型胶囊(RA / RS / WFD / ASQ),默认 WFD。
2. 题单按「最近考过日」倒序,一行一题:题号、题面首句、最近考过(几天前)、考过次数(三源合计)、押题标记、练过勾。
3. 点一行进单题页:题面(WFD 隐藏题面先听音频,点「显示」)、音频(公开 mp3 / TTS)、答案折叠、「练过」一键;上一题/下一题沿题单序走。
4. 一晚刷 20 题,练过的行灰掉,明天从没练的接着来。

**每行他要看到的(六格)**:题号 / 题面 / 最近考过 / 考过次数 / 押题 / 练过。

**要如实给他的真相**:「最近考过」是考生回忆,不是官方;三源的日期口径(duoink `e`、ynwac 评论日期、猩际确认考过)并排算,来源灰字小注。

**做成的标志**:打开页面十秒内开始做第一题;第二天回来能从上次断点接着刷。

## 故事二:小陈,考前 48 小时,只看押题

**她是谁**:明天考,只想看**这周真在考的**。

**她怎么用**:
1. 题单切「最近 7 天考过」窗口,再点「押题」筛(猩际预测清单 ∪ duoink hot ∪ ynwac frequent)。
2. 每型剩下几十题,一口气过完。
3. WFD/RS 用「随身听」模式:连播音频,不看题面。

**做成的标志**:一小时内把四型近 7 天考过的题全过一遍。

## 从故事推出的形

### 页面(展示层,照职位板形态)

- `/pte`(题单页):Shell 套壳 + 右上返回 + H1「PTE Core 机经」+ 白卡表。表 = JobsTable 那套形态(百分比固定布局、不横滚、手机卡片流)。
  - 胶囊行:题型(RA / RS / WFD / ASQ;批二后扩到 19 型)。
  - 窗口:近 7 天 / 30 天 / 90 天(默认 30)。
  - 筛:押题 / 未练过。
  - 排序:最近考过日倒序,同日按考过次数。
- `/pte/[type]/[id]`(单题页):题面 + 音频 + 答案折叠 + 练过 + 上一题/下一题。
- 文案四闸:一行一条、不用「·」「/」、术语统一(「考过」「押题」「练过」)、不解释(只留「考生回忆,非官方」一条免责)。

### 数据(数据层 `etl/pte` → mart → DB)

| mart 表 | 来源 | 列(草) |
|---|---|---|
| `pte_questions` | ynwac-bank / pb-bank / duoink-bank / ptexj-bank 合并 | id(源+源id)、type(标准码)、source、num、title、text(题面;猩际无)、answer、audio_url、image_url、predicted |
| `pte_recent` | recent.json | question_id、seen、seen_n、votes、freq、d30/d90/d180 |
| `pte_types` | 维度 | code、zh/en/ko 名、section、audio_kind |
| `pte_media` | media.json | question_id、kind、url、local |

- 跨源同题**不合并**(批一):一题一行按源,`最近考过`按源给;合并(按题型+标题对 duoink `tt`)留批三。
- 猩际只出信号(votes / seen / predicted),题面列空 —— 不造。
- seed 走既有 `lib/mart` 加载器,新维度表照 [新维度表六步](../../CLAUDE.md)(`payload_locked_documents_rels` 补列)。

### 资产(批三)

- 音频:ptebank 公开 mp3、ynwac SST mp3 已落盘;RA/RS/WFD 用 TTS 现合成(duoink 同法),Ollama 盒子或 Whisper 朋友 API。
- DI 图:已下载,`data/raw/pte/*/images/`。
- 练过/进度:登录用户存服务端(用户表加一列 JSON),匿名存 localStorage(小枫叶同法),登录后合并。

### 锁位(批四,等用量)

- 每日免费 N 题(初始 20),超额弹升级框;押题概率排序、随身听连播为 Pro。
- 埋点:`pte-open` / `pte-item` / `pte-done` / `pte-quota-hit`,按第 N 天维度。
