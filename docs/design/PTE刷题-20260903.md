## 故事一:小李,考前三周,每天刷 20 题

**他是谁**:PGWP 在手,省提名要 CLB 7,PTE Core 报了三周后的场。白天上班,晚上刷题;小枫叶 VIP 到期了不想再交,机经在几个群里零散抄。

**他的痛**:三家平台题库各不同,不知道刷哪些;题太多刷不完,想知道**最近真考过的先刷**。

**他怎么用**:
1. 打开 `/pte`,顶部四个题型胶囊(RA / RS / WFD / ASQ),默认 WFD。
2. 题单按「最近考过日」倒序,一行一题:题号、题面首句、最近考过(几天前)、考过次数(三源合计)、押题标记、练过勾。
3. 点一行进单题页:题面(WFD 隐藏题面先听音频,点「显示」)、音频(公开 mp3 / TTS)、答案折叠、「练过」一键;上一题/下一题沿题单序走。
4. 一晚刷 20 题,练过的行灰掉,明天从没练的接着来。

**每行他要看到的(六格)**:题号 / 题面 / 最近考过 / 考过次数 / 押题 / 练过。

**要如实给他的真相**:「最近考过」是考生回忆,不是官方;三源的日期口径(duoink `e`、ynwac 评论日期、猩际确认考过)并排算;**页面不标来源**(2026-09-03 Frank「没必要加来源」:用户要的是「最近考过」这个事实,不关心是哪家抓的;`source` 留库里做去重与对账,事实卡不出「来源」格)。

**做成的标志**:打开页面十秒内开始做第一题;第二天回来能从上次断点接着刷。

## 故事二:小陈,考前 48 小时,只看押题

**她是谁**:明天考,只想看**这周真在考的**。

**她怎么用**:
1. 题单切「最近 7 天考过」窗口,再点「押题」筛(猩际预测清单 ∪ duoink hot ∪ ynwac frequent)。

**做成的标志**:一小时内把四型近 7 天考过的题全过一遍。

## 从故事推出的形

### 页面(展示层,照职位板形态)

- `/pte`(题单页):Shell 套壳 + 右上返回 + H1「PTE Core 机经」+ 白卡表。表 = JobsTable 那套形态(百分比固定布局、不横滚、手机卡片流)。
  - 胶囊行:题型(RA / RS / WFD / ASQ;批二后扩到 19 型)。
  - 窗口:近 7 天 / 30 天 / 90 天(默认 30)。
  - 筛:押题 / 未练过。
  - 排序:最近考过日倒序,同日按考过次数。
- `/pte/[type]/[qid]`(单题页):答题卡 + 右侧事实卡(手机叠下),动线见下节。
- 文案四闸:一行一条、不用「·」「/」、术语统一(「考过」「押题」「练过」)、不解释(只留「考生回忆,非官方」一条免责)。

### 单题页答题动线(2026-09-03 Frank「答题参考一下他们的网站」;抄小枫叶 `practice#ra/#rs/#asq/#wfd` 与猩际 `practice/*` 的 crawl 缓存)

两家的答题页拆开看骨架一样,都是**三段一条线**:

| 段 | 小李看到什么 | RA | RS | ASQ | WFD |
|---|---|---|---|---|---|
| ① 准备 | 官方一句指令(英文原句)+ 倒计时 + 「跳过准备」 | 题面亮出,准备 33–40 s | 无准备,直接播 | 直接播 | 直接播 |
| ② 作答 | 题目音频(只播一遍,1.0x 可调)→ 输入区 | 录音(40 s 内,停 3 s 自动停) | 录音 | 录音 | 打字框 + 词数 + 计时 |
| ③ 对照 | 「显示文本 / 答案」默认折叠,交了才开 | 我的录音回放 + 示范朗读 | 原句 + 回放 + 示范 | 答案词 + 回放 | 逐词标红对照原句 |
| 尾 | 「已记为练过」自动打 + 一排钮:下一题(主)、重做、上一题(次) | | | | |

**钮只有一排、两种形**(2026-09-03 Frank「按钮样式保持一致,不要有重复」):主钮一颗(作答态=提交,对照态=下一题)+ 次钮同形(重做 / 再听一遍 / 上一题),全走通用 Button 桶;底部不再另起「上一题 / 下一题」链接排(与钮重复),「跳过准备」「停止」是行内文字动作不是钮。

**抄的**:三段线、只播一遍、准备倒计时可跳、显示文本默认折叠(RS / ASQ / WFD 题面就是答案,先看等于没练)、「考过 (N 人)」与押题标记挂题头、上一题/下一题沿题单序、进度 `12 / 137`。

**不抄的(批二不做,写明为什么)**:
- AI 评分(猩际 VIP 主卖点,小枫叶要用户自配 key):没有官方评分器,自己训不值;先给「回放 + 示范朗读」让他自己听,评分留 Pro 位。
- 翻译 / 一句话模式 / 同步跟读 / 流式刷题 / 评论区 / 优秀答案:都是围着评分和社区长出来的枝,与「今天刷 20 题」无关。
- 乱序 / 标记 / 跳转题号:题单页的活(批二先用「未练过」筛顶替乱序)。
- 语音人(猩际 Steven / Blake):TTS 只出一个声音,盒子合成(批三)。

**我们多做的一样**:WFD 对照用逐词标红(小枫叶只给原句让你自己比,猩际要 VIP 才判);本地 diff 一行算,不需要后端。

**录音怎么落**:浏览器 MediaRecorder 本地录本地放,不上传(阶梯③ 原生特性;上传是评分的事,评分不做就不传)。

**题型怎么称呼**(2026-09-03 Frank「英文缩写人家能明白是啥意思吗」):RA / RS / ASQ / WFD 是 PTE 考生圈通用黑话,两家都拿缩写当大字招牌(猩际左侧色块 `WFD` + 右侧 Write from Dictation;小枫叶蓝胶囊 `WFD #1` + Write From Dictation)—— 备考的人一眼认得,但没开始备考的人不认得。照本站「代码不裸奔」:**主文案 = 本语人话题型名**(听写句子 / 朗读 / 复述句子 / 简答题,`pte_types` 三语列),**英文全名 + 缩写灰字小注**在题卡头一行;H1 只放「听写句子 #11」一行放得下。

**参照图**(crawl 缓存离线渲染 + 登录态实拍,`img/参照-*`):小枫叶 WFD 手机 / RA 桌面,猩际 WFD 手机 / RA 桌面,多墨 ASQ 桌面(缓存是桌面视口拍的渲染态,手机版收不窄;图标字体没缓存显方块)。多墨走的是另一路:题头一行 `ASQ 15/151 · Hot · #10216 · Level 1 · Not practiced 2025-11`,ITEM TRANSCRIPT 与 EXAMPLE ANSWER **默认展开**、点「CLICK TO HIDE」才收,音频 8 个随机人声,START 一颗钮录音 —— 是「看着答案练」的复习流,不是考试流;我们照小枫叶/猩际的折叠(先练后看),但把多墨那行「上次练 2025-11」抄进练过格(批三进度)。小枫叶的免费账号一进单题就弹升级会员框(锁在门口,不是用过再锁)—— 反例,我们的锁位照当日拍板「用过再锁」。缓存渲染法:渲染态 outerHTML + 缓存 main.css,`page.set_content` + 拦掉一切外网请求,弹框节点摘掉再截 —— 与实拍只差 logo 图,以后看竞品不用登录。

### 题下评论区(2026-09-03 Frank「加评论有什么问题吗」→ 批二就带)

三家评论区都看过了(参照图 `img/参照-小枫叶*` 评论在页底、`img/参照-多墨评论-*`、猩际在「练习讨论」页签):
- **小枫叶**:一条评论一个「[考试记录] 日期:2026-08-29 Toronto」结构行,自由文字是附带;评论就是「最近考了」的原料。
- **猩际**:「确认考过」做成钮(考过 (413)),讨论区另开页签,里面多是老师长文。
- **多墨**(6 年老站,一道 RA 攒 95 条):每条评论带**分类标签**(Chitchat / Cheer up / Memories / Experiences),按赞 / 按时间排,点赞,一层回复,可匿名,发框在底部带分类下拉;另有 BEST 页签 = 别人的录音 + AI 三项分(Content / Pronunciation / Fluency)—— 评分产物,我们不做。

**小李在题下看到什么(从三家收敛)**:
1. 「考试记录」一栏:一行一条 `2026-08-29 Toronto`,按日期倒序;头上一颗钮「我考到了」(日期默认今天、城市选填,登录即发,**免审**),发了立刻进这栏,并合并进右侧事实卡的「考过次数 / 最近考过」(自家池子 + 三源抓取合并计数,不标来源)。
2. 「留言」一栏:自由文字,复用新闻评论那套(登录可评 → pending → 后台过审公开、昵称脱敏、一层回复、单人待审 10 条上限);按时间倒序;空态一句「还没人留言」。
3. 不做:点赞、按赞排、分类标签(多墨的四类里三类是闲聊,我们把唯一有数据价值的 Memories 做成了结构化的「考试记录」,剩下的就是留言)、匿名、BEST 录音榜。

**为什么免审只给「考试记录」**:结构化两格没有广告位,不用人看;自由文字才走人工闸(挡中介,新闻评论同款理由)。

**数据**:Comments 集合加 `qid` 字段(与 `newsSlug` 并列,一条评论只挂一处)+ `kind`(`exam` / `note`)+ `examDate` / `examCity` 两格;DDL 三列一索引 `(qid, status, created_at)`。`exam` 类 beforeChange 直接 `status=approved`。

**状态机(展示层,`components/pte`)**:`ready → answering → checked`;RA 从 ready 起,其余三型从 answering 起(音频自动播);`checked` 时写练过(登录用户存服务端,匿名 localStorage,批三定形)。
