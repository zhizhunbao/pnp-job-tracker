# 抽选类别统一 —— 以「抽选类别」为唯一实体,各省与联邦一套形(2026-09-13)

> Frank 2026-09-13「根据抽选 能来个统一的设计吗」。状态:**待 Frank 点头**,未开工。
> 前情:同日三批已把每期抽选接上门槛(操作列 → 门槛弹框 → 按类别对照 → 按抽选表逐类别补条文),
> 数据够了,形还是拼出来的:两张人工表各管一半、每省一套规则形制、弹框各段有无看运气。本稿把它们收成一个实体。

## 0. 一句话

**每一期抽选属于一个「抽选类别」;类别一张维表,记它属于谁(省 / 项目 / 通道)、要什么(门槛 / 限定职业)、怎么算分(分制 / 分值表)、还开不开(状态)。前端只认类别键,各省与联邦同一张卡、同一个页。**

## 1. 现状(2026-09-13 事实)

| 事实 | 数 |
|---|---|
| 抽选来源 | 8(BC / AB / MB / ON / NB / NL / PE + 联邦) |
| 分制 | 5(SIRS / WEOI / MPNP EOI / OINP EOI / CRS),NB / NL / PE 无分 |
| 类别名拼法 | 61 种(NB 一条流 18 种写法;联邦「Version 1/2/3」各算一种;MB 一轮拆 4~5 行) |
| 人工表 | 2 张:译名表 41 条(zh 灰注)、对照表 61 条(门槛 / 项目 / 职业清单) |
| 门槛表形制 | 一省一个 to_*_req,键集各省不同(ON 15 格、AB 15+条件格、MB 16 格) |
| 弹框段 | 本期 / 限定职业 / 通道资格 / 资料库 —— 有没有职业、有没有分,各类别不一 |

病根:**类别没有身份**。抽选行、译名、对照、职业清单、分值表各自拿「官方原文拼法」当键,官方改一个字就断一处,每接一省就多一张人工表。

## 3. 设计

### 3.1 数据层:类别维表 + 别名表(替代两张人工表)

**新维表 `draw_categories`**(mart 一文件 = 一张表;人工核定表 `data/processed/draw_categories.json` 手排版,改值只许字符串替换):

| 列 | 例 | 说明 |
|---|---|---|
| key | `mb-swm-grad` / `fed-healthcare` / `bc-care-health` | 类别键(slug,全站唯一,URL 用它) |
| province | MB / FED | 省码或联邦 |
| program | MPNP / AAIP / EE | 项目 |
| pathway | Skilled Worker in Manitoba | 所属通道(官方名) |
| name | Completed post-secondary study in Manitoba | 官方类别名(主文案) |
| name_zh / name_ko | 在曼省完成学业 | 译名(现译名表并入) |
| status | open / closed / replaced | 开放 / 已关闭 / 已并入(replaced_by 指向新键;ON 三条 EJO 流的先例) |
| scale | MPNP EOI | 分制(与分值表 system 对齐;无分留空) |
| rule_streams / rule_programs | [...] | 门槛通道名 / 联邦项目码(现对照表并入) |
| occ_streams | [...] | 限定职业清单名 |
| url | 官方抽选页 | |

**别名表 `draw_category_aliases`**:`(province, 官方原文拼法) → key`。抽选 ETL 每行按别名表归到 key;**硬闸:抽选行 100% 对到 key,对不上的拼法 exit 1 打印出来等人核**(不是静默留空)。NB 的 18 种拼法、联邦的三个 Version 都在这一张表里收口。

**`pnp_draws` 加 `category_key`**,`stream_zh` / `rule_streams` 两列退役(译名与对照都从维表取)。DDL 一句加列 + 一句灌维表。

**门槛表不动形**:各省 to_*_req 键集照旧,类别维表只记「取哪几条通道」;这一刀不动规则引擎。

### 3.2 展示层:类别卡(全站一个组件,弹框与页面共用)

段序固定,缺数据的段**不出也不占位**(只有「通道资格」缺才出「本站未收录」空态):

1. **头**:官方类别名主文案 + 译名灰注;第二行 省全名 + 所属通道;第三行状态(开放中 / 已于某日关闭,并入 X)
2. **本期**:省码胶囊 / 日期 / 分数线(带分制名)/ 邀请数 / 官方附注
3. **近四期**:本类别自己的四期,日期 / 分数线 / 邀请数(数据已在 pnp_draws,按 key 取)
4. **限定职业**:清单 + 数量,前五条 + 「全部 N 个」展开(BC 定向类别 / AB 科技专线 / 联邦类别有;没有不出)
5. **通道资格**:对到的通道条文(现弹框第二层)
6. **分够不够**:该分制的分值表前四大项 + 「用我的档案算分」钮(落注册闸 → 档案算分是代劳,归收费面;事实免费)
7. **官方页 / 资料库**

### 3.3 类别页 `/draws/[key]`(第二期)

同一个组件 + 底下全部历史期次表;SEO 落地面 = 61 个类别页。标题 = 官方类别名 + 省;JSON-LD 走现成 JsonLd 壳。

### 3.4 不做

- 不自造评分口径:「分够不够」只列官方分值表,算分入口进注册闸后再做。
- 联邦「Provincial Nominee Program」轮次:没有对应门槛组,卡只出本期与近四期。
- BC「Innovate」与偏远医疗两类:官方无职业清单,不出限定职业段。
