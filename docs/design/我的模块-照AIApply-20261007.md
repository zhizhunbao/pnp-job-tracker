### 外框

1. 作为登录用户,我进「我的」,页签顺序是 **我的求职 / 我的收藏 / 我的简历 / 我的订阅**,默认落在「我的求职」(10-05 定稿第 1 条,V1 没做;现在是 简历 / 收藏 / 求职 / 订阅、默认简历)。深链键不改(`sjobs|favs|resume|sub`),定稿里「改成 apps|plan」撤 —— 改键只多一张新旧映射表,用户看不见。
2. banner 副题改成「已投 N 封」(定稿图就是这样;现在的「简历、收藏与订阅」和页签重复,文案四闸该删);一封没投过不出副题。
3. 作为没登录就点了深链(邮件、职位页「邮箱投递」)的人,登录后回到原来那条深链(`/account?sec=sjobs&job=…`),不是落到首页。做法:跳登录时带 `next=`,登录框成功后只认站内相对路径。

### 我的求职(含投递区)

照 AIApply「Your Jobs」:一行一岗、状态一格、更新时间、最右操作(铅笔改稿 = 我们的「继续」草稿,Open = 我们的「打开」);点开能看「提交了什么」= 我们的简历 / 求职信两列。不照的:顶部三张计数卡、All / Applied / Declined 子签(09-23 不做清单)、右侧抽屉(通用桶没有)。

4. 作为投过的人,表照现在(职位 / 公司 / 市 / 投递日期 / 投递状态 / 职位状态 / 简历 / 求职信 / 操作),列一个不加不减;手机一岗一张职位卡,照现在。
5. 作为写了一半的人,**草稿也在表里**:排在最前(最近改的在前),投递日期格空、投递状态「草稿」、简历 / 求职信格空,操作格一颗主钮「继续」→ `?sec=sjobs&job=<id>`,投递区带着草稿的信和选过的简历打开。手机卡右上角是「继续」。
6. 作为刚点了「发送」的人,投递区收起,表上方出一条绿色成功条:「已发给 <公司>」,表里新多的那一行就在最上面。刷新后成功条消失(不记状态,同付款成功条)。
7. 作为点了已投过的职位的「邮箱投递」进来的人,投递区不再是空白:出一条灰字「这个职位已于 <日期> 投递」。
8. 作为还没投过的人,空态只有一行「还没有投递」+ 一颗「去职位板」。

**纠错**

- 投递表只列 sent / replied / bounced,草稿不列(`MYJOBS_APPLIED`)→ 改成也列 draft;写到一半关了页的人现在找不回那封信,这是数据丢失级的坑。
- 发出后 `ApplySection` 直接返回 null、`AppliedList` 重取 —— 用户只看到投递区消失,没有任何「成功」字样(10-07 缺口 1)。
- 已投过的岗从职位页进来,`SENT_STATUSES` 命中后返回 null,整块空白。
- 空态文案「还没有投递记录。在职位页点「邮箱投递」后,这里会记下来。」是解释句,改成空态引导。

### 我的收藏

照 AIApply「Saved Jobs」:每条一个动作钮(能自动投的 Auto Apply,不能的 Go to Listing)+ Delete。我们:能投的「投递」,不能投的只有「打开」;「取消收藏」= Delete。不照的:批量投递(AIApply 也是逐条点;定稿的勾选框 + 底栏按 10-05 分批表排在第一笔付费之后)。

9. 作为收藏过岗位的人,表照现在(职位 / 公司 / 市 / 薪资 / 发布日期 / 投递状态 / 职位状态 / 操作),操作格的「打开」换成主钮「投递」:在架、没投过、库里有投递邮箱的岗才换;点了去 `?sec=sjobs&job=<id>` 走投递区(职位名本来就能点开职位描述,「打开」在这几行是重复的)。已投递的、已下架的、没邮箱的照旧「打开」「取消收藏」。
10. 手机卡:右上角仍是「取消收藏」,能投的岗卡底一行「投递」钮。
11. 表下面的周报开关照现在。

**纠错**

- 收藏了的岗要投,得先点「打开」进职位页再点「邮箱投递」,绕两步(10-07 缺口 3);清单接口要多回一格「有没有投递邮箱」(`hasEmail`),线格式加一格。

### 我的简历

照 AIApply「My Resumes / My Cover Letters」:标题行右上「+ New Resume」,下面**卡片网格**(电脑三列),底稿标「Base Resume」= 我们的「默认」;求职信同一套卡片网格,每张 岗位 + 公司、创建时间、Download / Open。不照的:Share、浏览数、翻页(一人最多 20 份)。

12. 作为传过简历的人,顶上一行:左「简历 3 / 20」,右一颗主钮「添加简历」(现在在列表最底下,传第二份要先滚到底)。下面卡片网格:电脑一行三张、手机一列;一张卡 = 首页缩略图(裁到固定高、点开即预览,照 10-06 拍板)+ 文件名 + 「默认」绿标 + 「上传于 日期 · 47 KB」一行灰注 + 操作(设为默认 / 替换文件 / 下载 / 删除,小描边钮)。
13. 没传过的人,照现在:一块上传区(选择文件 / 拖进来)。
14. 作为投过或写过信的人,简历网格下面一段「求职信」:同一套卡片,一张 = 职位名 + 公司 + 「写于 日期」+ 已投递(绿标)或 草稿(灰标)+ 操作(已投递:打开 PDF / 下载;草稿:继续)。数据 = 投递表里有信的行(含草稿),不另建表;一封信没有就不出这一段。
15. 「投递信息」(英文姓名)和「我的条件」(四题)两段这一轮不做:姓名在投递第 1 步每次都能改;四题弹框那批没上。

**纠错**

- 「添加简历」在最底下,和 AIApply 的右上角相反。

### 我的订阅

照 AIApply「Billing」:一个在用订阅一张卡(产品名 / 周期 / 价格 / 续费日期 / Cancel),加 Update Card。我们是一次性包:卡上是 Pro + 还剩几天 + 有效期至 + 到期不会自动续费 + 「续买」;没有 Cancel(没自动续费就没有取消)、没有换卡(每次付款 Stripe 现填)。

17. 下面「Pro 包含」五条(只出 `price.perk.*` 的名字,不带说明句;和定价框共用一份词),再一行灰注「30 天 CA$5,90 天 CA$13」。
