1. **回答什么问题**:本站认哪些移民通道 —— 一条通道一行:属于哪省哪个项目、官方英文名、中 / 韩名、官方用哪几组抽选邀请它、门槛表里是哪条流、配额表里是哪一行、职业清单是哪张、现在开着还是关了。

## 四、通道对照表长什么样

通道对照表写在 `etl/pathways/constants.py`(09-28 改判,原拟 `data/raw/pathways/pathways.json`:raw 只放抓来的东西,人工判读的对照住代码),一条通道一段,注释挂官方原句、出处与判读理由(为什么这组抽选算邀请这条路),照 `etl/pnp` 各省页面配置表的写法;域产出 `data/mart/pathways.json`(列对齐库表)再进库:

| 格 | 例(BC 技术工人) | 说明 |
|---|---|---|
| key | `bc-skilled-worker` | **我们的**编号:直白、稳定、不随官网改名(规则见下) |
| plainZh / plainEn / plainKo | BC 技术工人 / BC Skilled Worker / BC 숙련 노동자 | **我们的**显示名:按需求整理的直白叫法(三语一套,中韩 = 职位板 PNP 格那个) |
| officialName | Skilled Worker stream | **官方**英文原名:照抄这条通道自己那一页的写法(魁省 / NB 另有法文的,另记 officialNameFr) |
| province / program | BC / PNP | program:PNP / AIP / EE / 试点 |
| boardLabel | (空) | 具名通道 = 岗位 `pnp_stream` 的取值;省默认通道空 |
| isDefault | true | 本省可提名但没挂具名通道的岗落到它 |
| drawStreams | ["Innovate: High Economic Impact"] | 官方用来邀请它的抽选组(抽选表 stream 原值) |
| reqStreams | ["BC PNP Skilled Worker stream", "BC PNP Skills Immigration (all streams)"] | 门槛表的流名(照 `pnp_requirements` 现有取值) |
| quotaKey | (空) | 配额表通道键(阿省那种公布到通道的才有) |
| occLabels | [] | 职业清单的 label(具名清单通道才有) |
| status | open | open / paused / closed(安省旧 8 条 = closed) |
| url / quote | welcomebc.ca/… / 原句 | 出处 |

**两套名字**(2026-09-28 Frank「一个是官方的,一个是我们基于需求整理的直白的」):
- **官方的**:officialName 照抄通道页;drawStreams / reqStreams / quotaKey / occLabels 照抄官网各页的写法 —— 同一条通道各页写法不一

- 官网改名(抽选组换名、流名改写)当轮就报出来,不再等人看弹框才发现。
