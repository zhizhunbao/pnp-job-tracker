- 作为 Frank,我看 `docker compose logs jdformat` 能看到每轮整理了多少条、失败由头是什么;查库 `count(jd_formatted)` 能看到在招岗的整理版覆盖率每天在涨;不烧朋友网关的额度(批量走家里盒子)。

## 现状链(改前)

```
用户 / Googlebot JS 渲染 点开岗页
  └─ useJdFormat → POST /api/jobs/jdformat {url}
        └─ jobsJdformatRoute:jobs.jd_formatted 命中直回;缺 → generateJdFormatted
              └─ friendChat(朋友网关 ngrok,qwen3.6)→ validateJdFormatted → UPDATE jobs SET jd_formatted
```

三个事实决定方案:

1. **整理版只有一条来路**:线上懒生成。生产 open 岗 76,996 条,有整理版 15,135 条(20%);近 7 天生成 16,801 条,几乎全是 Google 重抓 JS 渲染触发的 —— 朋友网关在替爬虫干活。
2. **列已经在**:`jobs.jd_formatted` / `jd_formatted_at`(docs/sql/jkm-lazy-ai.sql),seed 的 jobs upsert 不碰它们(不在 COLS_JOBS),线上写的值一直保着。
3. **家里盒子够用**:192.168.1.150 Ollama qwen3.6,同一条 5.7k 字原文实测 10.9 秒出五节、标记齐、数字校验过;company brief / news 已经在用它(NEWS_LLM_BASE)。

## 方案:etl/jdformat 域(一域一役,role=jdformat,1h 一轮)

```
mart/jobs.json(build 每小时产)
  └─ jdformat format 步:在招(open/campus)且有正文、还没 ok 的岗,按 datePosted 新→旧,每轮 ≤ JDFORMAT_LIMIT(400)
        └─ Ollama /api/generate(PROMPT_HEAD 镜像 cms;失败一次加「照抄数字」句再打一次)
              └─ validate(五节标记齐 / 长度 / 多位数字必在原文)→ processed/jdformat/formatted.json
                    (externalId → {status, formatted, term, hrs, model, at, note, src_len};每 20 条原子落盘;
                     fail 7 天冷却;不在当前 mart 在招列的记录每轮剪掉)
mart 汇装(下一轮 build):add_job → fill_formatted
  └─ jobs 行加 jdFormatted / jdFormattedAt;employmentTerm / employmentHours 只填空(官方标注优先)
seed:COLS_JOBS 加两列,进 COLS_JOBS_COALESCE
  └─ mart 有 → 覆盖(同一套口径,盒子版更新);mart 没有 → 保留线上懒生成版
```

### 边界三问

- **回答什么问题**:「一条岗的五节整理版从哪来」。
- **和已有域切在哪**:mart 只汇装不生成(生成要打模型,一轮几十分钟,不能塞进 build 链);cms 懒生成路保留给「还没轮到」的岗。切法判据 = 「批量 vs 按需」,不是「哪个模型」。
- **寿命**:与职位板同寿;cms 懒生成路依赖它没有,它依赖 cms 没有 —— 两边只共用 DB 一列与文件契约。

### 两方言镜像(记欠账)

提示词与校验口径的主人是 cms `lib/jobs/prompts.ts`(JD_FORMAT_PROMPT_HEAD / JD_FORMAT_RETRY_TAIL)与 `lib/jobs/constants.ts`(JD_* 一族)、`functions.ts`(jdDraftOf / validateJdFormatted / jdMarkLinesOf)。Python 侧 `etl/jdformat/constants.py` 第 4、5 段与 `functions.py` 第 3、4 段逐字镜像,两边文件头都写了「改那边必同改这边」。两方言无法共用一份源(JSON 装不下注释,提示词不进 i18n),这是本站第二处跨语言镜像(第一处:行业分组 BROAD_TO_GROUP)。
