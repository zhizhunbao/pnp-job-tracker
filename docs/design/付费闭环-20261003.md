## 为什么(最近 7 天 umami,09-26 → 10-03,已扣 Frank 两台设备)

- 真实访客约 29、访问 34、浏览 53;每次访问 1.6 页,一半只看一页。
- 会用:打开职位正文 14、翻译 4、省提名弹框 3、相关职位 3、AIP 弹框 1。
- 全是 0:投递、注册、存搜索、进「我的」、定价、升级、付费、发起付款。
- 根因不是不会用,是路上没有付费点:职位板锁列清单是空的(PRO_COLS),普通访客只会碰到存搜索超限、AI 日额度用完、右上角定价链接三处,一个都碰不到。
- 盲区:未登录点「投递」直接弹登录框,这一下不计数(`useApply` 的 onApply),投递 0 说明不了没人想投。

## 硬约束:职位页正文永远不挡

Google 招聘结构化数据规则:用户不登录就要能看到职位详情,需要登录才能看正文的职位不收录,违者人工处罚并撤下(https://developers.google.com/search/docs/appearance/structured-data/job-posting)。
所以 `/jobs/<id>` 职位页正文从不被盖住;弹窗只出现在站内动作上。抖音来的人敲 offer2pr.com 落职位板,同样走「用一会再弹」。

## 用户故事

1. 作为从 Google 落到某个职位页的人,我能直接读完这条职位,不被打断。
2. 作为在站内挑岗的人,我点开前两个职位都正常看;点开第 3 个时,先弹出三道点选题,答完注册,注册完回到我刚才点的那个职位。
3. 作为任何时候点了「投递」或「收藏」的人,不管点开过几个职位,都直接弹同一套三道题 + 注册(动作本来就要账号)。
4. 四道题全是点选,不打字(10-03 Frank 改:「第一个问题应该是,是找工作还是拿 PR,然后再问你是什么专业,想找什么工作,然后再是你现在在哪个省」):① 目标(找工作 / 拿 PR)② 专业(统计局 CIP 2021 大类 01–11 + 其他;官方表 https://www.statcan.gc.ca/en/media/4226 ,上线前落 crawl 层)③ 想做什么工作(10-03 Frank「选工作要不要依据之前选的专业」「我项目不是都分类好了吗」→ 用本站职业分类树:专业经一张十几行的「专业大类 → 本站职业大类」对照表〔lead 手写、Frank 抽查,放数据层〕挑出几个大类,胶囊列这些大类下的职业,按在招数排;刚看的职位预选在最前;专业选「其他」或跳过 = 全部大类;不用普查交叉表)④ 现在在哪个省(十省含魁北克 + 加拿大境外;时区预选,中国时区预选境外)。原「身份」题撤:境外由第 ④ 题兜住,工签类型挪到第一次投递时问。答案落统一存储,注册后进档案,代投、筛选、推送都读它。
5. 作为注册完的人,我第一次投递时上传简历、填求职信,累计免费投 3 封;第 4 封弹出统一定价弹框。
6. 作为付费用户,我可以用卡订阅月 $5 / 季 $13(自动续费),也可以用微信 / 支付宝买 30 / 90 天(不自动续费)。

## 竞品参照(10-03 Frank「参考一下其他代投网站呢」,只读调研,多处是二手评测)

- 建档题:通行做法是「简历 + 3~5 项偏好」,几乎每家都问目标职位、地点、薪资;签证 / 担保只在面向留学生和移民的产品里问(Massive、Jobright 的 H1B)。我们的「身份」题就是这一格,不删。

- 免费额度:LoopCV 终身共 10 份、Wobo 每天 5 份永久免费;另一派先付费或付费试用。我们一辈子 3 封算紧的。
- 价格:订阅主流 US$24~45 / 月,按量约 US$0.4~1 / 份;季付通常约 75 折。我们 CA$5 / 月约为市场价的 1/6~1/10。中文人工代投按家收费,12~16 元一家,要求求职者交出自己的账号密码。

- 信任:差评集中在扣费(试用期自动续费、投满一定份数就拒绝退款),不在投递质量;常见的信任设计有先审后投、每份留截图、每日上限。批 2 加「发出前预览」,批 S 做到一键取消 + 续费前提醒。
