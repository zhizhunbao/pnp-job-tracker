统一规则

  1. 顺序固定:① 结论 → ② 申请门槛 → ③ 名单 → ④ 配额 → ⑤ 抽选;没有的不出。
  2. ① 结论:能走 =「本岗能走的通道」,一条通道一张子卡(英文官方名 + 中文灰字);走不了 =「本岗不满足的门槛」,只写原因词(兼职 / 定期合同 / 季节工 / 临时工 / 职业不收 / 工资低于中位)。三个弹框都有;EE 新增,QC 新增。
  3. ② 申请门槛:标题统一「申请门槛」(原「本岗通道的门槛」);走不了的岗也照样显示。多条通道(QC)在一张卡里按通道分小节,不再一通道一张卡。
  4. ③ 名单:职业清单 / 指定雇主 / EE 类别清单,一律表格,本岗那一行高亮置顶,其余折叠「展开其他 N 个」。省提名的清单从最后挪到这里;EE 的类别清单从第二挪到这里。
  5. ④ 配额:照旧。
  6. ⑤ 抽选:标题统一「抽选」(原「本省抽选」「AIP 抽选」「最近分数线」);一律表格。不抽选的只写一行「不经抽选」;删掉「省提名与 AIP 同池选取…」「不设分数线,按本省劳动力需求…」「持雇主 offer 直接递申请…」这类说明句。ON 的「改制前的抽选」作为第二张抽选卡放最后。

顺带修的

  • NB 走不了的岗缺「本岗不满足的门槛」和门槛卡(线上实测 food service supervisor:直接从配额开始)—— 补上。
  • AIP:删判定卡;指定雇主只列本岗雇主 + 同招牌几家,全省名单跳雇主板;职位板不再预载 3863 家。

不在这批

  • 育空、西北地区职位板 PNP 列是空的(弹框打不开),是数据层没接,另开。
  • 职位板 AIP 列的加盟店标签(「部分门店」),等你定用词。
