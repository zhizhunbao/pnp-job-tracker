## 每家长什么样

### LinkedIn Job tracker

- 一张白卡:左上「← Job tracker」标题;下面一排**胶囊页签带计数**:`Saved · 0`(选中绿底)、`In Progress · 0 ▾`、`Applied · 0`、`Interview · 0`、`Archived`;右上「Date posted ▾」排序。
- 空态:插画 + 「No jobs here」+ 一句 + 主钮「Find more jobs」;卡底一行「Not seeing some jobs?」。
- 没有顶部横幅、没有侧栏;页面就是一张卡。

### Indeed My jobs

- 标题「My jobs」;四签**计数在签名上方**:`0 Saved / 0 Applied / 0 Interviews / Archived`。
- 空态:「No applications yet」+「Keep track of job applications here.」+「Find jobs」。
- 帮助中心:Applied 签每行有「Update status」(Interviewing / Offer received / Hired / No longer interested)和「⋯」(Archive / Report / View details 含当时用的简历 / Withdraw);状态分三类 —— 自己改的、雇主改的(Application viewed / Employer reached out / Not selected)、Indeed 判的(Employer reviewing / Response seems unlikely / Job closed);六个月后自动归档。

### Teal Job Tracker

- 顶部**阶段箭头条带计数**:`6 BOOKMARKED › 3 APPLYING › 7 APPLIED › 3 INTERVIEWING › 1 NEGOTIATING`。
- 下面一张干净的表:勾选框 / Job Position / Company / Min Salary / Max Salary / Location / Status / 日期;表头可排序;状态是灰字。
- 右侧浮层「Attachments」:这一岗附的简历 + `Match 67% · Score 75%`;「Excitement」五星。
- 深绿主色,左侧细窄导航栏,表格无竖线、只有横细线。

### Simplify Job Tracker

- 「My Submitted Applications」:一岗一张**横卡**,左公司 logo,右边四格**进度点** `Applied › Screen › Interview › Offer`(走到哪一步点到哪一步)。
- 「My Saved Jobs」:两列**卡片**,logo + 职位 + 公司 • 地点 + `Full-Time` 胶囊;卡底两颗文字钮「Saved」「Details」。
- 「My Job Tracker」:看板列带计数 `SCREEN (5) / INTERVIEWING (4) / OFFER`;浮层「Your Job Search Summarized」桑基图(450 投 → 265 没回音 / 177 拒 / 50 电面 / 20 面试 / 8 offer)。
- 浅蓝灰底,白卡圆角,一切都是卡。

### AIApply(10-05 已查)

- 「Your Jobs」表:logo + 公司、**状态标签**(Preparing to apply / Applying Now / Applied / Failed / Declined)、岗位、更新时间、改稿 / Open;子签 `All 1127 / Applied 750 / Declined 131` **带计数**;顶部三张计数卡。
- Resumes / Cover Letters:三列卡片网格,标题、创建时间、两颗钮,底稿标「Base Resume」。

## 结论(建议)

1. **「我的求职」改成进度板**:顶上一排阶段胶囊带计数(草稿 N / 已投递 N / 雇主回复 N / 退信 N;点一枚只看那一类,同 LinkedIn),下面一岗一张横卡:公司首字母块、职位、公司 + 城市、状态胶囊、投递日期、材料(简历 / 求职信 两个小链接)、右边一颗下一步(草稿「继续」、已投「打开」)。五家全都把阶段计数放最上面,09-23「统计三格不做」改判。
2. **「我的收藏」同形横卡** + 右边「投递」主钮(能投的)/「打开」。
3. **「我的简历」照 AIApply 卡片原样**(Frank 10-08 已选):文件名、默认标、上传于、两颗钮、⋯ 菜单;求职信同一套卡。
4. **「我的订阅」照 SaaS 账单页**(现在这版的结构不变:方案卡 → 包含 → 付款记录),只换皮:白卡、圆角、钮统一。
5. **整体风格**:照片 banner 换成页标题行(「我的」+ 已投 N 封;五家没有一家在个人区放宣传横幅);卡圆角 12–14px、细边 1px、无阴影;主钮一种(蓝底胶囊),次钮一种(白底描边);状态胶囊五色(草稿灰 / 已投递蓝 / 雇主回复绿 / 退信红 / 已下架橙)带圆点;字号两档(标题 15 / 正文 13.5)。
6. 不抄:看板拖拽(Teal / Simplify)、桑基图、Excitement 星、Withdraw、六个月归档、Archived 签。

## 不做 / 待定

- 公司 logo:公司表没有图标字段,先用首字母色块(10-05 待拍板 5 的推荐);真图标另立批。
- 「雇主回复」计数要中转回信那批(apply-relay)上线才有数,先出 0。
- 阶段胶囊点选 = 前端筛同一份清单,不加接口。
