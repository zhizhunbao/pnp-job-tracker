# 全站 hover 风格统一(2026-07-31)

> 起因:Frank 2026-07-31「全站的 hover 样式是不是要统一一下风格」。
> 本文=设计决策稿(设计先行,拍板后并入「组件换装批」施工,不零敲碎打)。

## 1. 现状盘点(2026-07-31 实核,全站 hover 共 8 处)

| 类别 | 现状 | 问题 |
|---|---|---|
| 文字链接 | 全局 `a:hover{filter:brightness(.75)}`(E8-08 #121) | ✅ 已统一,保留 |
| 按钮 | 全局 `button:not(:disabled):hover{brightness(.94)}` | ✅ 已统一,保留 |
| **行级链接**(landing 职位榜/职业榜、新闻行、抽选行……整行是 `<a>`) | 吃全局 a:hover → **整行文字变暗** | 读起来像被禁用;与「格子/卡」的底色高亮语言打架 —— 本次统一的主对象 |
| 职位板可点格 | `.jcellAct:hover{background:#eff6ff}` | 底色高亮,自成一派 |
| 资源卡 | `.resTile:hover{border-color:#bfdbfe;background:#f8faff}` | 底色+边框,自成一派 |
| 七目标卡/省卡等卡片链接 | 吃全局 a:hover 整卡变暗 | 同行级链接问题 |
| 列宽把手 | `.colResize:hover{background:#93c5fd}` | 特化控件,不动 |

## 2. 提案:三个 token,两个新增一个沿用

效果图(左=现状,右=提案):

![hover统一效果图](../assets/mockups/hover统一-效果图.png)

1. **行 hover `.rowHover:hover`** = `background:#f8fafc; filter:none`(新增,styles.css)
   —— 整行可点的列表行(职位榜/职业榜/新闻/抽选/日更大数字链接)。底色高亮替代文字变暗,内容原样。
2. **卡 hover `.cardHover:hover`** = `border-color:#bfdbfe; background:#f8faff; filter:none`(新增,styles.css)
   —— 卡片形态的链接(七目标卡、省卡、方案卡、资源卡)。取 resTile 现值升级为全站 token,resTile 换装后删自有样式。
3. **文字链接/按钮** —— E8-08 全局规范原样保留,不动。

**铁律(Frank 2026-07-31 拍板):只有能点的地方才 hover,不能点的地方不要 hover。**
与 E8-08 #121「可点必有态,不可点必无」同义,升级为换装批的验收项:灰态卡(选专业)、纯文本、
灰注、禁用钮一律无 hover 无 cursor;反向也查——发现有 hover 态但点了没反应的,要么接上行为要么摘掉态。

判定口径:内容是**一行**的可点元素挂 ①,是**一块**的挂 ②,行内文字链接维持 ③;`.jcellAct`(#eff6ff)并入 ①(色值统一成 #f8fafc)或保留更深一档 —— 待拍板(表格格子比整行小,#eff6ff 的辨识度有它的道理,倾向保留)。

## 3. 落地方式

- styles.css 加两个 class(共 6 行),挂类即生效;`filter:none` 覆盖全局 a:hover 变暗,行/卡内部的文字链接仍走全局规范。
- 存量换装并入**组件换装批**(与「禁点号清理」同批):landing 榜行/新闻行/抽选行、七目标卡、/stats 省卡、/pathways 方案卡、resources 资源卡。逐页过一遍,一次 session 收完。
- 触屏无 hover,不做任何 JS 兜底(现状也没有)。
