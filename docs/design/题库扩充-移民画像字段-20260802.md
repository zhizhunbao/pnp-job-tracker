# 题库扩充 — 移民画像字段设计

> 2026-08-02 · 动机:PR 卡只有 4 道题(status/clb/exp/prov),职业规划和选省份各只有 1 道,区分不出「刚毕业大学生」和「工作五年的人」。
> 前置:《统一题库与付费面》(20260731)定下了字段库架构(q/unlocks/tier);本文在此基础上扩字段、不改架构。

## §1 现状:引擎能用但没问

省评分引擎(`pnpSelfScore.ts`)已为每个维度写好匹配器:

| 维度 | AUTO_PICK 键 | SelfProfile 字段 | 当前取值 | 现状 |
|---|---|---|---|---|
| 学历 | `education` | `edu` | **写死 highschool** | ❌ 没问 |
| 年龄 | `age` | `age` | **写死 0** | ❌ 没问 |
| 总经验(含海外) | `work` / `work5` | `expRecent` | 只取加拿大经验 | ⚠️ 偏低 |
| 旧经验(6-10年前) | `work610` | `expOlder` | **写死 0** | ❌ 没问 |
| 第二语言(法语) | `language2` | `clb2` | **写死 0** | ❌ 没问 |
| 首要语言 | `language` / `language1` | `clb1` | ✅ clbBand 有问 | ✅ |

**结果**:换省对照算的是下界中的下界——学历按高中、年龄按 0、海外经验按 0。加 3 个字段就能把精度拉到位。

## §3 新增字段(3 + 2)

### 立即可用(插进引擎就生效)

#### ① `eduBand` — 最高学历

```
unlocks: 换省估分(education 因素), 未来 CRS 估算
tier: free
engine: edu → SelfProfile.edu
```

| 档位 | 值 | engine 映射 | 要点 |
|---|---|---|---|
| 1 | 高中或以下 | highschool | |
| 2 | 大专 / 一年制证书 | diploma2y | PGWP 1-2 年 |
| 3 | 本科 | bachelor | PGWP 3 年, CRS 120 |
| 4 | 硕士 | master | CRS 135, 部分省有硕士通道 |
| 5 | 博士 | doctorate | CRS 150, 少数省有博士通道 |

**为什么重要**:BC SIRS 学历分 0-26 分,SK SINP 0-23 分。写死 highschool = 每个省都少算十几分。

#### ② `ageBand` — 年龄段

```
unlocks: 换省估分(age 因素), 未来 CRS 估算
tier: free
engine: age → SelfProfile.age (取区间中点)
```

| 档位 | 值 | engine 映射 | 要点 |
|---|---|---|---|
| 1 | ≤24 | 23 | CRS 接近峰值 |
| 2 | 25-30 | 28 | CRS 峰值区间 |
| 3 | 31-35 | 33 | CRS 开始下降 |
| 4 | 36-40 | 38 | CRS 明显下降, 部分省扣分 |
| 5 | 41+ | 43 | CRS 跳崖, SK 年龄分 0 |

**为什么重要**:SK SINP 年龄分 0-12 分(18-35 满分,≥50 为 0);CRS 年龄分跨度 0-110。35 岁和 25 岁走同一条路成功率差很多,但现在报告体现不出来。

#### ③ `totalExpBand` — 总工作经验(含海外)

```
unlocks: 换省估分(work 因素), FSW 基本门槛
tier: free
engine: 与 expBand(加拿大经验)联动 → SelfProfile.expRecent / expOlder
```

| 档位 | 值 | engine 映射 | 要点 |
|---|---|---|---|
| 1 | 没有 | 0 年 | 应届生,只走毕业生通道 |
| 2 | 不到 1 年 | 0.5 年 | |
| 3 | 1-3 年 | 2 年 | FSW 最低 1 年 |
| 4 | 3-5 年 | 4 年 | CRS 满分区间 |
| 5 | 5 年以上 | 5 年 | BC SIRS 满分区间 |

**与 expBand 的关系**:
- `expBand` = 加拿大经验 → 决定 CEC 资格(≥12 个月)
- `totalExpBand` = 全球经验(含加拿大)→ 决定省评分 work 因素

engine 映射逻辑:`expRecent = max(totalExp, canadianExp)`(加拿大经验是总经验的子集,取大的那个)。`expOlder` 目前不单独问(留给未来探索层)。

### 探索层(需数据支撑,列入路线图)

#### ④ `frenchBand` — 法语水平

```
unlocks: 换省估分(language2 因素), CRS 双语加分(30-50分), 法语区通道
tier: pro
engine: clb2 → SelfProfile.clb2
```

| 档位 | 值 | engine 映射 |
|---|---|---|
| 1 | 不会 | 0 |
| 2 | 初级 | 4 |
| 3 | NCLC 7+ | 7 |
| 4 | NCLC 9+ | 9 |

**为什么 pro**:双语加分是「别人想不到但很值钱」的精确结论,符合「结论收费」原则。
**为什么列路线图**:SK 分值表有 language2,BC 没有;需确认哪些省的分值表真包含此因素再上线。

#### ⑤ `marriedBand` — 配偶情况

```
unlocks: CRS 计算基准(有配偶/无配偶是两套分制), 部分省加分
tier: pro
engine: 标志位(有配偶时 CRS 各项满分更低)
```

| 档位 | 值 |
|---|---|
| 1 | 单身 |
| 2 | 有配偶,配偶非加拿大人 |
| 3 | 有配偶,配偶是加拿大人/PR |

**为什么列路线图**:CRS 的有/无配偶分制完全不同(相当于两张分值表),本站现在没有 CRS 计算器,上这个字段之前要先把 CRS 估算做起来。

## §5 answers.ts 变更

新增字段加入 Answers 类型:

```ts
export type Answers = {
  // --- 现有 ---
  status: string
  nocs: string[]
  provs: string[]
  done?: boolean
  clbBand: number
  expBand: number
  provBand: number
  crsBand: number
  pgwpBand: number
  // --- 新增 ---
  eduBand: number       // 0=未答, 1-5 对应高中→博士
  ageBand: number       // 0=未答, 1-5 对应≤24→41+
  totalExpBand: number  // 0=未答, 1-5 对应0年→5年+
  offerBand: number     // 已有(从 fields.ts),answers.ts 补声明
}
```

EMPTY 补零,readAnswers/writeAnswers 自动兼容(已有的 num() 对新字段返回 0 = 未答)。

## §6 report.ts `selfFromAnswers` 变更

从硬编码改成读真实答案:

```ts
// 现在(下界中的下界):
self: { edu: 'highschool', expRecent: months/12, expOlder: 0, clb1: clb ?? 0, clb2: 0, age: 0 }

// 扩充后:
self: {
  edu: eduFromBand(answers.eduBand),           // 真实学历
  expRecent: Math.max(totalYears, canadianYears),  // 加拿大与总经验取大
  expOlder: 0,                                      // 未来 frenchBand 上线后才拆
  clb1: clb ?? 0,
  clb2: 0,                                          // 未来 frenchBand 上线后读
  age: ageFromBand(answers.ageBand),           // 真实年龄段中点
}
```

`only` 白名单同步扩:答了 edu → `only.add('education')`;答了 age → `only.add('age')`。

## §7 问题顺序(体验)

一屏内按自然对话顺序排:

1. **你做什么工作?**(OccPicker,不编号)
2. ① 你现在什么情况?(status)
3. ② 最高学历?(eduBand)
4. ③ 年龄段?(ageBand)
5. ④ 英语到哪一档?(clbBand)
6. ⑤ 做过这行一共多久?(totalExpBand)
7. ⑥ 其中在加拿大多久?(expBand)
8. ⑦ 手上有 offer 吗?(offerBand)
9. ⑧ 目标省?(provBand)

逻辑:你是谁(1-3) → 技能(4) → 经验(5-6) → 工作(7) → 去哪(8)。

每张卡只取自己需要的子集(见 §4),序号按实际显示的题目连续编号。

## §9 不做的事(YAGNI)

- ❌ **不建 CRS 计算器**:CRS 是另一个引擎,复杂度高,留到有付费验证后再上
- ❌ **不问配偶/家庭人数**:引擎还没消费这些字段,问了也不能改结论
- ❌ **不问法语**:SK 分值表有 language2 但 BC 没有,覆盖面不够;路线图里列着
- ❌ **不问具体 CLB 分数**:档位足够驱动现有逻辑,精确分数是 CRS 计算器的事
- ❌ **不区分「大专 vs 一年制证书」**:对省评分差异太小(rank 2 vs 3),先粗分再说
