# 职业分类两级 —— 用户故事版(2026-09-23)

> 起因:2026-09-23 Frank 看职位板「这个分类结构,需要一个大表格重新归类一下,很多 EE 类别,小分类是空的,是不是删掉中分类还是怎么处理」,选「两级:大类 + 职业」;「大表你确定就行了」;「比如科技下面不需要在分类了吗」(答:不加第三层,见「为什么不要第三层」)。
> 一句话定位:**职位的分类从「大类 → 中类 → 小类」三级改成「大类 → 职业」两级**;职业 = 统计局 5 位职业码,界面上显示人话短名,码只在类别弹框里出。
> 执行顺序:① 数据(定稿大表,已落 etl/noc)→ ② 展示(本稿)→ ③ 清理(中类 / 小类退出数据层,另批)。改错层下游白干,顺序不许倒。

## 用户故事

### 故事一:小林,只想看软件开发的岗

**她是谁**:多伦多,三年后端经验,找「写代码」的活。

**她的痛**:以前大类选「IT」,中类只有一个「IT」,小类是「软件与网页开发」—— 软件开发者、软件工程师、计算机程序员、网页开发四种职业混在一格;很多中类下只有一个小类,小类那格显示「—」,她不知道还能往下分什么。

**她怎么用**:
1. 常用一行大类选「IT」。
2. 大类后面紧跟一个「职业」下拉:IT 经理、信息系统专家、软件开发者、软件工程师……按在招数从多到少排,15 个一屏。
3. 选「软件开发者」,表里只剩这个职业的岗;地址栏是 `?broad=IT&noc=21232`,发给同学打开一样。

**做成的标志**:两下点选,不用猜中类、小类是什么意思。

### 故事二:老王,看一条职位的详情

**他怎么用**:面包屑是「安大略 › IT › 软件开发者」,点「软件开发者」回到板上筛好的列表。表格的「职业」列、点开的类别弹框都说「软件开发者」,和面包屑是同一个名字;弹框里再给职业码 21232、官方英文名、TEER 和职责。

### 故事三:英文用户(88% 流量)

同一个下拉,选项是英文短名(Software developers …),按在招数排;英文短名缺的 99 个职业本批补齐(见「数据」),补齐前退回官方英文名(准,只是长)。

## 为什么不要第三层

两级里的「职业」本身就是大类的细分。27 个大类里职业最多的是制造 68、技工 47、医疗 45,其余多数不到 35;科技只有 15 个。再加一层 = 把十几个职业分成三四组、每组两三个 —— 就是旧的中类 / 小类,空格子和「—」正是这么来的。长下拉按在招数排序,常用的在最上面;哪天真嫌长,把那个大类劈成两个大类,不加层。

## 界面改什么

| 地方 | 现在 | 改成 |
|---|---|---|
| 职位板 · 常用一行 | 大类下拉;中类、小类两个下拉在折叠区 | 大类后面紧跟一个「职业」下拉(09-23 Frank「职业分类筛选,是不是放到全部大类后面比较好」):选了大类只列该大类的职业,没选大类列全部;按在招数从多到少;选了 EE 类别再按 EE 名单收窄;换大类时清掉已选的职业;框宽按最长选项量(Frank「这个下拉跑偏了」)。折叠区「职业分类」一行撤 |
| 职位板 · 可选列 | 「中分类」「小分类」两列 +「NOC」列(显示码,排在职位后面) | 一列「职业」,紧跟「大分类」(Frank「table 部分职业是不是也放到大类后面」):显示人话短名、不折行;原「NOC」列改名改内容,点开仍是类别弹框 |
| 类别弹框(点职业格) | NOC 码、官方名、TEER、大 / 中 / 小类、职责 | 职业、职业码、官方名、TEER、大类、职责 |
| 职位详情 · 面包屑 | 省 › 大类 › 中类 › 小类 | 省 › 大类 › 职业 |
| 相关职位的兜底链(两组都空时) | 小类 → 中类 → 大类 逐级探 | 只探大类(职业那一级已由「同省同职业」组承担) |

**不动**:大类下拉与大类列;EE 类别下拉、列、胶囊(Frank「先都留着」,两级做完再定);统计页(就业把脉)照旧用中类;问卷 / 规划页带多个职业码的深链照旧显示成可清除的胶囊;老深链 `?mid=` / `?fine=` 仍能筛(只撤控件,同 09-23 撤筛选时「深链照旧」的先例)。

## 数据

- **大类**:etl/noc 的 classify;09-23 按定稿大表挪 6 个码(20012 IT 经理 工程→IT;11100 会计师、14200 会计文员 金融→会计;12201 / 12202 / 12203 保险理赔、承保、估值 会计→金融)。
- **职业名**:noc_descriptions 的短名(中 title_zh_short、韩 title_ko_short、英 title_en_short);中文按定稿大表人工裁决 68 条(etl/noc SHORT_FIX,含纠错名 22310 电气电子技术员、22302 工业制造技术员、21210 统计精算师等)。缺短名退回完整译名,再退回官方英文名。
- **英文短名补齐**:缺的 99 个(官方名超 32 字符、模型压的没过校验就留空,覆盖在招约 1 万岗)本批人工补进 SHORT_FIX_EN。
- **下拉选项与排序**:noc_openings(每轮灌库刷新,一个职业码一行,带大类与在招数),进职位板的大维度包(懒取,不进首屏)。
- **筛选值** = 职业码,URL 用现成的 `noc` 参数(问卷 / 规划页深链同一个口径)。
