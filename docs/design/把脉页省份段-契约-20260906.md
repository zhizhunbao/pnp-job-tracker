## 1. raw/statcan/<pid>.json(statcan 域产出,一表一文件)

```json
{
  "source": "https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1710012101",
  "pid": 17100121,
  "title": "Estimates of the number of non-permanent residents by type, quarterly",
  "freq": "Q",
  "fetched": "2026-09-06",
  "series": { "npr": "Total, non-permanent residents", "asylum": "Total, asylum claimants, protected persons and related groups", "workOnly": "Work permit holders only", "studyOnly": "Study permit holders only", "workStudy": "Work and study permit holders", "other": "Other" },
  "byGeo": { "CA": { "2026-04-01": { "npr": 2558562, "asylum": 0, "workOnly": 0, "studyOnly": 0, "workStudy": 0, "other": 0 } }, "ON": {} }
}
```

- `freq`:`Q` 季度 / `M` 月度 / `A` 年度;`byGeo` 的期键 = WDS `refPer`(`YYYY-MM-DD`)。
- `geo` 码:`CA` 全国 + 十省两位码(ON QC BC AB SK MB NB NS NL PE);领地不收。
- 四张表与键:

| pid | 键 | 维度成员(memberNameEn,精确匹配) | latestN |
|---|---|---|---|
| 17100009 人口 季度 | `pop` | Geography 单维 | 46(≈2015 起) |
| 17100121 临时居民 季度 | `npr` / `asylum` / `workOnly` / `studyOnly` / `workStudy` / `other` | 见上 json `series` | 46(表从 2021-07 起,取满) |
| 36100222 GDP 年度 | `gdp` | Prices = `Chained (2017) dollars`;Estimates = 含 `Gross domestic product at market prices` 的那一个成员(成员名以 metadata 为准) | 12 |
| 14100287 失业率 月度 | `unemp` | Labour force characteristics = `Unemployment rate`;Gender = `Total - Gender`;Age group = `15 years and over`;Statistics = `Estimate`;Data type = `Seasonally adjusted` | 140(≈2015 起) |

- WDS 原始响应先进 crawl 层:`crawl.put_cached_page(CachePutIn(slug="statcan", url=<DATA_URL>#pid=<pid>, html=<响应原文>, title=<cubeTitleEn>))`,再抽 json。
- 值缺位(WDS `value` 为 null / 抑制)= 不落键,不折 0。

## 2. mart 表 `macro_series`(长表,一行一点)

| 列 | 类型 | 说明 |
|---|---|---|
| geo | text | `CA` / 省码 |
| key | text | 见 §3 键表 |
| period | text | 季度/月度 = `YYYY-MM-DD`(refPer);年度 = `YYYY` |
| freq | text | `Q` / `M` / `A` |
| value | numeric | 值;官方缺位的点不出行(不折 0) |
| as_of | text | 该点数据截至(年度完整年 = `YYYY`;进行年 YTD = `YYYY-MM`;季/月 = period 本身) |
| unit | text | `people` / `dollars_millions` / `percent` / `nominations` |
| source | text | 官方页 URL |
| fetched | text | raw 抓取日 |

唯一键 (geo, key, period)。产出 `data/mart/macro_series.json`,seed 与其余表同机制;DDL `docs/sql/macro-series.sql`(建表 + 索引 + `payload_locked_documents_rels.macro_series_id`),collection `MacroSeries`。

## 3. 键表(前端行名 ↔ 数据键)

| key | 来源 | freq | 行名(zh) |
|---|---|---|---|
| pop | statcan 17100009 | Q | 总人口 |

| workOnly / studyOnly / workStudy / asylum / other | statcan 17100121 | Q | (前端算:其中工签 = workOnly + workStudy;其中学签 = studyOnly + workStudy;其中难民申请人 = asylum) |

## 4. 通用表格序列能力(components/table)

```ts
export type TableSeriesIn<T> = {
  pointKeys: string[]                         // 时间点列的 key,升序;非此清单的列固定显示
  valueOf: (r: T, key: string) => number | null
  labelOf: (r: T) => string                   // 图例名
  recent: number                              // 「近 N 期」默认显示末 N 列
  words: { table: string; chart: string; recent: string; all: string; indexNote: string }
}
// TableIn<T> 新增可选 series?: TableSeriesIn<T>
```

- 有 `series` 时表壳内网格上方出工具条(右对齐):`近 N 期 · 全部` 两态文字 + 两枚图标钮(IconTable / IconTrend,lucide `Table` / `ChartLine`,亮色 = 当前态)。
- 表态:只显 pointKeys 的末 N 列(全部 = 全显);趋势态:表体换成 `SeriesChart` —— 一张 SVG 多折线,y = 指数(每行首个有值点 = 100),x = 点列的 label 文本,图例 = 颜色 + labelOf + 最新原值,点上 `<title>` 原值;整行不足 2 个点不画。
- 桶导出:`Table`(带 series)、`SeriesToolbar`、`SeriesChart`、`useSeriesView`(手机卡复用同一套)。
- 文案由调用方经 `words` 传入,桶不携词。
