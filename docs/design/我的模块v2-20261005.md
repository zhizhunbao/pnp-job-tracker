## 用户故事

### 结构

1. 作为登录用户,我进「我的」(/account),电脑上 banner 下左侧栏四项、右边内容;手机上 banner 下一行四个页签:求职 / 收藏 / 资料 / 订阅(英文 Applications / Saved / Profile / Plan)。默认落在「我的求职」。
2. 作为从邮件点进来的人,深链 `?sec=apps|favs|profile|plan` 直接落对应页签;旧值 `resume|sjobs|sub` 映射到新页签,其余落默认。`?ok=1` 付款成功提示照旧挂在内容最上面。

### 我的求职

3. 作为投过简历的人,手机上一岗一张职位卡,右上状态标签:雇主已回复(绿)/ 已投递(蓝)/ 退信(灰),卡底「投递于 日期」;电脑上是表格。雇主已回复的置顶,其余按投递时间倒序。
4. 作为求职者,我点一张卡(一行)打开往来弹框,手机整屏、电脑中号:上面本岗职位卡,下面两签。
   - 「往来」:一封一行(时间、发出 / 收到、标题),收到的展开原文。
   - 「投出的材料」:当时发出的简历和求职信 PDF(点开能看)、发件人「<英文名> via Offer2PR」、回复地址。
   - 底部「查看职位」。
5. 作为还没投过的人,我看到「还没有投递」+「去职位板」。

### 我的收藏

6. 作为收藏过岗位的人,手机职位卡、电脑职位板形的表;每条左(电脑)/ 右上(手机)一个勾选框;投过的挂「已投递」、下架的挂「已下架」,这两种不能勾。
7. 作为勾了 N 个的人,底栏「已选 N 个」+「批量投递 N 个」(手机固定在屏底)。超额规则照 10-03 稿。

9. 想取消收藏,回职位页点星;列表里不加删除钮。

### 我的资料

10. **简历卡**:文件名(点开预览)、上传日期、打开 / 替换 / 删除;没传过只有「上传简历」。投递页第 1 步传的就是这一份。现在的「简历文字存档」界面退役,抽出的文字照样存,供匹配用。
11. **求职信模板卡**:信的前几行,职位名、公司名两处占位标色;「编辑」在弹框多行框里改。投递页第 2 步改过的信就是这一份。
