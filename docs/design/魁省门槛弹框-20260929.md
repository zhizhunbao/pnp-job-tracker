## 一、用户故事

- 我在职位板上看到魁北克的焊工岗,PNP 那一格原来只写紫字「魁省」、点不开。改完写「PSTQ 高技能」,点开是这个岗能走的
  每一个通道各一张门槛卡。
- 焊工这张弹框有三张卡:PSTQ 通道 1(高技能专才)、PSTQ 通道 3(受监管职业,第一行写明「仅建筑业焊工、压力容器焊工」,
  执照行写监管机构)、PEQ 临时工分支。护士只有通道 3 一张;厨师只有通道 2;TEER 0–3 的岗再加 PEQ 那张。
- 法语一行我一眼看懂要考多少分:「TEF 口语 400 分、书面 300 分起」,灰字「魁省口语 7 级、书面 5 级;TCF 口语 10 分、书面 6 分起」。
- 卡里只有官方门槛,没有「能不能拿到」「好不好走」这类解读;抽选、配额、收件窗口卡这一版不出(PEQ 的收件期本身是门槛,留在 PEQ 卡里)。

## 二、判据

1. **岗位能走哪几条通道,按官方「职业 → 通道」对照表,不按 TEER 推**(受监管、部分受监管、要公民身份这些 TEER 推不出来)。
   PEQ 临时工分支按官方门槛「TEER 0–3」在数据层算。
2. **门槛照录官方**:每行出处是官方原句(pnp_requirements.label),卡片文字是按结构化字段套三语模板。
3. **法语主写 TEF**:魁省只认法语,TEF / TEFAQ / TEF Canada 在魁省对照表里是同一套分数线。不折成 CLB(同一魁省级数在联邦 NCLC
   表里因考试而异:TEF 口语 400 ≈ NCLC 5,TCF 口语 10 = NCLC 7)。分数线在数据层按魁省对照表算好,前端只显示。
4. **魁省不属省提名**:pnpEligible 照旧 false(mart NON_PNP_PROV 不动);判定引擎与官方规则页暂不读魁省门槛行。

## 四、前端

- 格子:魁省岗查 qc_noc_streams(按 NOC),取第一个通道写「PSTQ 高技能 / PSTQ 中低技能 / PSTQ 受监管」;查不到照旧「魁省」。可点。
- 弹框:魁省岗走魁省分支 —— 每个通道一张门槛卡(版式照「本岗通道的门槛」卡,标题 = 官方原名,灰字 = 界面语言名,右上来源)。
- 行名:职业档 / 适用 / 执照 / 法语 / 工作经验 / 学历 / 收件条件 / 收件期 / 年龄 / 自给 / 配偶 / 杰出成就。文案进 i18n 三语。
