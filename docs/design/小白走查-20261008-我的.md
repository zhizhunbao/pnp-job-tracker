## 2. 发现分级

### 🔴 卡死

无。

### 🟠 以为坏了

1. **智能投递投到魁北克 / 阿尔伯塔**(18、19、49):这条动线从注册到开启没有一道省份题,候选岗按职业全国取。他看到 3 条魁北克岗会以为「这功能乱投」。根因:动线缺省份;开启那一刻也没让他看一眼「将投哪里」。困惑分 5。
2. **「跳过」两处不一致 + 找不回**(27、28):卡上没了,清单仍「待投」,点「继续」无反应,刷新后消失。根因:状态没刷到清单;跳过没有回头路 **(本地已改:跳过钮已删)**。分 4。
3. **草稿 / 待投行的「继续」是死钮**(28、30):同页内的软跳转只改了地址栏,流程不开;整页刷新才开。根因:同页 `?job=` 变化不触发流程装载。分 4。
4. **「AI 3 次试用已用完」但他只见过 1 封**(28、37):另两次被智能投递在后台写掉了(卡上看不出哪封是 AI 写的);英文号 5 张全是模板,一封 AI 信都没见到。根因:计数在后台扣,结果不可见。分 4。
5. **注册完落到 PR 评估问卷**(03、45):他要的是「我的」,被要求答 11 题。根因:注册成功的落地写死 `/plan/pr`,不管他从哪来。分 4。
6. **「去选想做的工作」= 进 11 题问卷,关掉回不来**(16–19):只想选一个职业,却进了申请人条件问卷,关掉后落在 PR 评估页。根因:职业题复用问卷,没有单题出口,也没带 `next` 回「我的」。分 4。
7. **头像菜单没有「我的」**(05):点头像只有退出登录;「我的」藏在汉堡菜单最后。根因:入口藏着。分 4。

### 🟡 看不懂

8. **「今日待投」空态是三项勾选清单**(07、48):标题说待投,内容是准备工作;三个圈勾满才出「开启智能投递」。他不知道这三项是为了什么。根因:一个卡位承载两种状态(准备 / 队列)却用同一个标题。分 4。
9. **待投卡不说用哪份简历、发到哪、署谁名,「投出」一点即发**(22、23、25);**「全部投出 4」一点发 4 封**(26、49)。分 5 **(已知,本地已改:ApplyCheck 逐项检查 + 全部投出已删)**。
10. **第一张卡是贴合的 AI 信,后面全是两段模板**(22 对 26):同一张卡位两种质量,他会以为模板那封「没写完」。根因:AI / 模板两档没有标识。分 4。
11. **日期全是明天**(11、25、40):今天 10-08,上传于 / 最近改于 / 投递于都显示 2026-10-09。根因:按 UTC 取日。分 3。
12. **城市只有中文「康山」**(22):待投卡上城市只给中文译名,没有 Concord;清单与收藏行是「魁北克市 Québec QC」中文在前英文灰注在后,与 10-08「英文在上、译名灰字在下」规则相反。分 3 **(换装批待做,已知)**。
13. **收藏行没有「投递」钮**(34):收藏了想投,只能「打开」再找详情页底部的钮。根因:动线少一跳。分 3。
14. **「每周邮件摘要」默认勾上**(08):他没勾就订了邮件。信任类。分 3。
15. **开着智能投递时去手动投一岗,今日待投卡整个消失**(36):他会以为队列没了。根因:同一卡位被投递流程占用。分 3。
16. **关掉智能投递,卡没了但清单仍「待投 3」**(29):两处状态不一致。分 3。
17. **第 3 步收件人只有公司名,没邮箱**(40)**(已知)**;**求职信 PDF 文件名溢出框**(40)。分 3 / 2。
18. **订阅页 Pro 清单没有智能投递**(10、41)**(已知)**:开着的这功能到底免费还是付费,两页都看不出。分 3。
19. **Stripe 商品名没写 30 天**(42):名字已改 Offer2PR Pro,时长还是看不到。分 2。
20. 小处:简历「1 / 20」上限;「No applications yet」与上方 5 张待投并排(49);英文页签能横滚但没有任何可滚的提示(47);中文「今日待投」英文「Ready to send」不是一个意思。分 1–2。

### 🟢 顺

- 注册框一步成;顶栏立刻变头像。
- 简历上传 → 默认 → 预览 → 删除有内联确认可取消;姓名保存立即打勾。
- 开启智能投递约 35–40 秒出第一张卡;投出后绿条 + banner「已投 1 封」+ 清单新行带「简历 / 求职信 / 打开」。
- 收藏 / 取消即时;半路离开自动存草稿;关 / 开智能投递队列即回。
- 状态胶囊筛选好用;定价 → Stripe 一跳到位,商品名已是 Offer2PR Pro。
