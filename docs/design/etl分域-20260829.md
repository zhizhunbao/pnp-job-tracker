# etl 分域重构 —— 域即役、文件名整顿、三件套与 Ruff 闸(2026-08-29)

> 起因:Frank「之前的文件名就是太乱了」+「大部分 etl 域都要挂 docker 定时」。前身《ETL 目录重组设计方案》(2026-07-18,第 21 轮 #55,未实施,git 历史可考)的核心判断沿用,按六周后的现状翻新。
> 本文=设计方案,拍板后按批执行(一批一种变换)。

## 1. 判据(五条,全是宪法推论)

1. **域即役,一域一门**(2026-08-29 Frank:「每个域只有一个 main.py 作为主要执行文件」):一个域 = 一个目录 = 一个调度单元 = **一个入口 `main.py`**。META(method/interval)并进域 `__init__.py`,`sources/` 退役,META.steps 收敛为 main;`auto_update` 改扫 `etl/*/META`。抓什么、怎么洗、多久跑、从哪进,翻一处齐活。
2. **docker 留根不迁**:compose 编排的不只 etl(cms 容器、backup);它是基础设施(换掉它业务零改);盒子运维路径有迁移成本换不来「少翻」。域↔调度的耦合点在 META,加域零改 compose。
3. **文件名 `<动词>_<机构>_<内容>.py`**(2026-07-18 已拍):`scrape_` 抓原始页/feed 落 raw,`build_` 构建事实表,`watch_`/`check_`/`audit_` 哨兵与自查。文件名单独出现(日志/报错栈)也自述。
4. **省与地区住文件名,不住目录**:跨省横改是主访问模式(同构错误一次修全省),按省切子域正好切碎这一刀;命名前缀(`build_ab_*`)按字母序天然聚簇;省是数据维度不是代码域。
5. **子域等私件群长出来**:触发条件 = 目录翻不完(~15+ 且命名救不回)或某主题自带多文件私件群(现成例:pilot_extractors 并入 pilot/ 后即其子群)。默认一层到底。

## 4. 域内代码组织(Python 版三件套;与 cms 同一部宪法两种方言)

| cms | etl | 说明 |
|---|---|---|
| constants.ts | `constants.py` | 域词汇表/映射/正则/阈值,JSON 装得下的 |
| types.ts | **`scheme.py`** | TypedDict 行形状(对标 DbRow→Fact 三段律);只许 import typing/标准库。⚠ 名字两拍(2026-08-30):types.py 遮蔽标准库 types 实撞出局;Frank 拍 scheme —— Python 方言与 cms 唯一的抽屉名分叉 |
| functions.ts | `functions.py` | 域内共享纯函数;**单消费者的函数留在脚本里不搬** |
| routes.ts | **`main.py`(域内唯一入口)** | 编排本域全部步骤,逐步 try/except 隔离(一步炸不断别步,母脚本同款)+ 逐步报行数;单步调试 `python etl/<域>/main.py --only <步>` |
| —— | `scrape_*/build_*.py` | **步骤模块,不可执行**(无 `__main__`):IN_*/OUT_* 路径常量住模块头(宪法既有:运行时打印),对外只暴露一个 `run()` |
| variables.ts | 不需要 | 进程一次跑完无跨请求状态 |
| index/server 门 | 不需要 | 无打包边界;域间禁 import 靠闸 |

**模块内形制**:模块 docstring(是什么 + IN→OUT 一句话)→ import → IN/OUT 常量 → 域常量 → 函数(step-down)→ `run()`;`__main__` 只许 main.py 有;超 200 行加段横幅(`# ====` 三行框 + N. 编号);决策记录带日期挂常量上方;每函数 docstring + 签名类型注解(新写/大修就范,存量滚动);收尾打印产出行数 + 最少行数防线(etl 版四道闸地基:行数异常当场红,不静默入库);母/子框架照旧(通用件只住 fetch.functions,子脚本只填 SOURCE + parse)。

**三件套全站样张 = `etl/company/`**(2026-08-30 Frank 三令连发,lead 亲手:「先拿一个做样章」
「enrich/scrape 这些都要重构到其他三个文件里」「只允许 jsDoc 注释,不允许行内注释」):
**终态 = 全溶五件**:__init__(META)/ main(门,直调函数不 subprocess)/ constants / scheme / functions
—— 步骤文件消失,四步成 functions.py 四个段,段首放该步 IN_*/OUT_* 路径常量(路径要经 _paths

**Python 方言律全集**(2026-08-30 Frank 连环拍板,全部有 AST/Ruff 闸兜底,派工照抄 company):
① 注释只许 docstring(常量用赋值后裸字符串),行内 # 退役,段横幅三行框保留;
② functions 顶层只许函数(常量含 IN/OUT 路径归 constants,constants 特批唯一 import _paths);
③ 零字符串令:functions 体内禁一切字面量(文案 *_TPL 模板化、f-string 归零),豁免仅字典键/空串/数值;
④ 显式循环令:禁 lambda、禁四种推导式与 genexp,全改显式 for;
⑤ 一参令:函数至多一参且禁默认值,多入参收 scheme 的 XxxIn;入口(门直调的四件)零参,节奏参数归 constants;
⑥ 库形状 Protocol 自声明只真用的格(HttpClientLike 先例),检查器判不动时 cast 只住装配点;
⑦ sys.path 只有门(main.py)插一次,件套以包名(company.constants)被引;E402 全局豁免;
⑧ 抽屉名 scheme.py(types.py 遮标准库出局,Frank 拍名);
⑨ 简化优先于收编:零消费者的产出连逻辑带常量整体退役(csv/md 榜单先例),常量多先问逻辑肥不肥;
⑩ 形状全 dataclass(属性访问,字段键从 functions 消失);json 进出边界的键只许住 to_* 行构造器
(cms「db 词汇只许 to* 体内」直译)与 dataclasses.asdict;wire 键走 HDR_/P_ 常量词族;
⑪ 内嵌函数禁(出户成顶层具名,闭包变量收 XxxIn;cms tsx 同律)。
形制闸共九条 AST 硬规则兜底(check_etl_shape 文件头 ①-⑨)。

## 5. 闸(Ruff 现成规则全接,同 REFACTORED 滚动思路)

| 规矩 | Ruff |
|---|---|
| 签名类型注解 | ANN |
| 模块/函数 docstring | D |
| 复杂度/行数 | C901 + PLR0915 |
| 命名 | N |
| 裸 except / 吞错 | E722 + BLE001 + S110 |
| 禁跨域 import | TID(banned-api 按域配) |
| 存量不返工 | per-file-ignores 反用:全局开严,存量目录挂 ignore,改一域摘一行,只紧不松 |

Ruff 管不了的两条(IN/OUT 常量存在、收尾报行数)→ `ops/check_etl_shape.py` 自查役。

## 6. 迁移批次(一批一种变换)

1. **纯移动批**(1 session):git mv 双改(归目录+改名)→ 脚本头 `sys.path` 照 pnp 现成写法 → META steps 路径同步 → **验收:逐脚本实跑 + 09 全表行数与迁移前逐表相等** → 盒子 git pull(volume 挂载,免重建镜像)。风险低,回滚 = revert。此批脚本仍各自可执行,不动行为。
2. **一域一门批**:各域立 main.py(编排 + 逐步隔离 + 报行数),步骤文件去 `__main__` 收成 `run()`;META 并进域 `__init__.py`(steps → main),auto_update 改 glob,sources/ 退役;验收 = auto_update dry-run 发现清单与迁移前逐役相等 + 每域 main 实跑全链。
3. **形制滚动批**:新写/大修就范三件套与脚本内形制,Ruff 分域摘 ignore;不整批返工存量。

## 6.5 开域手册(批 2 落地后的日常;Frank:「想抓哪些域的数据,直接开域就行」)

1. `mkdir etl/<域>`,`__init__.py` 写 META(method/interval);
2. `scrape_<机构>_<内容>.py`:填 SOURCE 声明 + parse 函数(通用件全在 fetch.functions);
3. `build_<机构>_<内容>.py`:原始 → 事实表(需进库则 09 汇装点加一表 + docs/sql DDL 六步);
4. `main.py` 几行编排;
5. 完 —— auto_update 自动发现,docker 零改。
示例(Frank 举例 PTE Core 题库):`etl/pte/` = META(周更)+ scrape_pearson_pte_samples(SOURCE+parse)+ build_pte_question_bank + main;⚠️ 题库类看来源 —— 官方公开样题可抓,第三方商业题库有版权不抓。
⚠️ 批 2 落地后宪法「加新源 = 在 etl/sources/ 定义 META」同步改成本手册。
