  1. 删判定卡:「判定:能走 AIP(雇主在指定名单)」整张删。能走时由「本岗能走的通道」说。弹框只在格子写「指定雇主」时打得开,所以「雇主不在名单」「仅大西洋四省」永远看不到,不写;只剩两种走不了:不出通道卡,改出省提名弹框现成的「本岗不满足的门槛」卡(PnpBlockCard,同一套原因词:兼职 / 定期合同 / 季节工 / 临时工 / 职业不收)。
  2. 通道卡放最上面,子卡形态不动。
  3. 指定雇主拆表、只列相关的:招牌、门店、法人三列;弹框里只列本岗雇主一行(高亮),连锁招牌再列同招牌的其他加盟商;开弹框时现查这几行。全省名单改成链接「本省全部指定雇主」跳雇主板(AIP + 本省筛选,分页)。职位板不再预载四省 3863 家。拆名字在数据层 aip 域做,前端只显示;表格照职位板形态。
  4. AIP 抽选都列人数:单独抽的省(NB、NL)列 AIP 自己的轮次;同池的省(NS)直接列「NSNP + AIP」那组的轮次,组名已说明是合池,不加说明句。PE 不抽选,照旧一行「由指定雇主直接为候选人递背书申请」。
  5. 删两句同池说明:省提名与 AIP 同池选取,人数含 AIP(省提名弹框)、与省提名同池选取,人数见本省抽选(AIP 卡)。
