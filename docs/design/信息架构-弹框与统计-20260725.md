## 二、统计页设计(#127/#128/#132/#133,下一实施批)

### 2.1 下钻链(#127,P1)

```
L0 全部(按省/按大类) → L1 省内按大类 → L2 大类内按中类 → L3 中类内按小类 → 点条=职位板深链
```

- L0-L2 数据源=stats 表(province×broad×mid 行已入库);**L3(小类)现查 `/api/jobs` 聚合**(count by fine,带 prov/broad/mid 过滤),零 mart 改动。
- 面包屑「全部 › ON › 服务 › 餐饮」任意段上卷(现有交互延伸);末级点条直达 `/?prov=&broad=&mid=&fine=`(#142 深链现成)。
- 中位类指标依旧单省内下钻,不触碰跨省合并红线。

### 2.2 渲染修复(#128,P1,与 2.1 同批)

- 病根(实锤截图):下钻改变条数→容器高度跳变,ECharts 未 dispose 旧实例/未 resize → 残影透叠。
- 修法:下钻 setPath 时 `chart.clear()` 后 setOption(notMerge:true);容器高度用 chartH(items.length) 过渡动画关闭;类目 >20 切 TOP15+「其他」归并(点「其他」=展开全量列表页不出图)。

### 2.3 省卡重做(#133,P2)

- 位置:卡片区挪 /stats 最上(现「常见图表」之上)。
- 指标集:在招职位 · 省提名清单岗 · **最新工签数 · 学签数 · PR 数 · 移民难度**(scrape_ircc_stats + stats.difficulty 现成);**中位年薪撤**(省级单一中位=无效聚合,职业间方差远大于省间)。
- 难度显示沿用 E8-12 地点弹框口径(同源同文案),不另造标尺。

### 2.4 跨省对比入口(#132,P3)

- 文案自解释:「两省并排比岗位量/清单命中/难度 →」;是否保留 Pro 标随 #129 数据定。
