## 0. 一条链(用户视角,五层)

```
职位页(流量在这:67.5% 单页,google_jobs_apply 470/30天)
  → ①免费事实层(职位板/把脉三分表/门槛列/弹框——已建成,#284-#286 收口)
  → ②对话层(CTA/挂件/示例句:问题被答上,顺手建档)
  → ③档案层(表单/向导/对话 三路归一个档案)
  → ④判定层(#287 tripleVerdict:岗×雇主×档案 → 个人化结论 = 全站唯一新收费点)
  → ⑤付费与回访(锁合成不锁事实;档案在变=回访理由)
```

**今晚为什么显得断断续续**:①层在收尾抛光,④层刚立项,②③层今天实测发现全是断环——
补丁式汇报掩盖了它们本是同一条链的五段。

## 2. 断点清单(全部今晚实测举证,不是推测)

- **D1** 表 CTA 预填句「LMIA 获批雇主的表…有什么用?」被编排闸拒答(chat_logs err=noOcc 实录)——自家导流句撞自家闸。
- **D2** 追问轮短答「没工作」被 tooShort 误杀(chat_logs 实录)。
- **D3** 对话抽到的槽只进 chat_logs,从不回写 users.profile(chatOrchestrate 代码实查零写点)——最自然的建档场景是唯一不建档的入口。
- **D4** 示例句三句写死,不分三态(截图实指);带不出槽 → 点了也可能撞 D1。
- **D5** 三关(职业/雇主/个人)各自能判,没有拼装器(#287 设计 20260809 已出,真人 33102 案例锚定)。
- **D6** AIP 申请人门槛生产 0 行(实查)——#287 完美案例最快路判不了,硬前置。
- **D7** 真实付费 0;唯一瓶颈实测=锁区→定价 0.26%(08-03 账);雇主线全部产出至今是免费层。
- **D8** 回访理由缺(既有判断:留不住的根是没回访理由)——档案里 PGWP 在倒数、清单在变,站上从不据此说话(提醒信只有新岗)。

## 3. 分批(一批=一次能验完;顺序=依赖序)

- **批A 对话入口批(D1-D4,一个文件区,当天量)**:
  ①示例句三档动态化(匿名=场景句自带职业槽/注册未建档=边问边建档句/已建档=从他槽位模板生成,
  句句 #287 形状——三档句式见 08-09 对话记录,实施文档定稿);
  ②CTA 用法类问句走无 NOC 分支(答表怎么用+引导给职业);
  ③有对话历史时放行短答;
  ④登录用户高置信槽**只补空**回写档案+答复尾行告知(匿名不存,手填优先,隐私红线照旧)。
