统一规则

步骤名用一套词:雇主登记 / 拿雇主 offer / 雇主递职位审批 / 建 EE 档案 / 递 EOI / 进池与抽选 / 收邀请、递申请 / 省里审批 / 拿提名,递永居。各通道从这套词里取,顺序按真实流程。省提名各通道都列「进池与抽选」一步,不需要的写「不需要」—— 九省一眼看出谁要抽、谁卡在抽。

每步只写三类事实:谁做、多久(处理时长、递件期限)、现在怎样(窗口满额、改制后未抽、最近分数线)。都带官方原句,原句挂在步骤数据上,来源钮跳官方页。官方没写的那格空着,不猜。

卡住的那一步标橙色圆点(萨省限额行业的窗口、阿省和 EE 的抽选、安省的改制后未抽):用户先看哪一步最难。

④ 配额卡:萨省多出三行行业(数据层已有,优先行业 / 限额行业 / 其他行业的名额与已发提名);别的省有分通道配额的照阿省现有写法。

② 门槛卡:萨省补「身份」一行(限额行业只收现有员工),照阿省机会通道样张。本岗属于哪个行业不判(公司表没有行业字段),所以写成「限额行业:…」的条件句。

与 10-01 拍板的出入(要你确认)

10-01 定「不抽选的只写一行『不经抽选』,删掉『持雇主 offer 直接递申请』这类说明句」。这次「进池与抽选」那一步写「不需要:持 offer 直接申请」—— 算步骤里的事实,不是说明段落;你不同意就只留「不需要」三个字。

数据层要补的

新登记表:每条通道的步骤(步骤词、谁做、时长 / 期限、官方原句、出处页),住 etl/pathways 通道表旁边;萨省收件窗口表(Processing Statistics 页,工作日更新)进 pnp 域。橙字「待核」的格都要在这一步补原句,补不到就空着。
