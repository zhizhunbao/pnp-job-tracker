# 加拿大招聘板接入调研(2026-09-06)

> 起因:Frank 2026-09-05「加拿大还有其他招聘网站吧,之后把他们的数据也都接进来」;2026-09-06「第一步调研,然后排优先级接入」「用我的 crawl 工具」。
> 方法:九站全部走 crawl 域正门 `discover_urls`(httpx 直取,403/验证壳自动转有头浏览器),两轮:首页 depth 1 → 从缓存页里取真实列表链接再爬一轮。原文全落 `data/crawl/board-<站>/`(gitignore,manifest 可 grep),**禁猜 URL** 铁律全程遵守:第二轮种子全部来自第一轮缓存页的 `<a href>`。
> 重复率抽样:列表首页的行按「雇主名归一 + 职位名互含」对 `data/processed/jobbank/postings.json` 同省行比对,样本小(11~100 行),只当方向判据。

## 排序判据与顺序

判据:**补的岗数 ÷ 接入工作量**;聚合站一票否决(重复 + 反爬)。

1. **Jobboom + Jobillico**(直取、零重复、QC 是 Job Bank 最弱的省)。两站都是法语:职位名要过 NOC 分类器(`etl/noc`)才有 TEER,分类器对法语标题的命中率是接入前要先量的第二个数。
2. **SaskJobs**(直取、带 NOC 码、最省事;净增约两三成)。
3. **Québec emploi / GC Jobs / CareerBeacon / WorkBC**:各需再爬一轮(浏览器兜底或找接口)才能判,单独开小批。
4. **Talent / Eluta / Indeed 系**:结案不接。

## 接入形制

- 一站一域(`etl/<站>/` 五件套,照 `etl/ats/` 抄形),META 小时更;原文照数据链 crawl → raw → processed → mart:列表页与详情页原文走 `crawl.put_cached_page`,抽出的 json 落 `data/raw/<站>/`,跨源清洗(地点、薪资、试点打标)仍归 mart 域。
- `source` 字段记原板名,显示层不新增来源标签形制。
- 进库前先跑一次全量重复率(不是首页抽样),同雇主同职位同城的岗以 Job Bank 为准去重。

## 接入实施(2026-09-06 同日,Frank「两站都接,Jobboom 剔 Job Bank 转载」「一站一域」「原文全文落 crawl」)

**二次实测改判**(建域前又查了一轮,结论写进两域 `__init__` 头注释):

- Jobboom 英文站点地图 24,901 条里 **21,433 条(86%)是 Job Bank 转载**(URL 雇主段 `job-bank`,hiringOrganization 写 Job Bank,申请链接直指 jobbank.gc.ca),枚举时全剔,剩 3,468 条直发。
- Jobillico 搜索页是 JS 渲染,但站点地图 `sitemap_job_postings_1..4.xml` 列全 **35,310 个帖号**(22,045 英文版 / 13,265 仅法文),来自 2,282 家雇主的 ATS 喂帖;详情页 ld+json JobPosting 带发布日、截止日、街道邮编、薪资区间与单位、工时。
- **「从源头接」不划算**(Frank 问了两次,实测答):头部 14 家雇主的招聘系统 = iCIMS / Oracle HCM / BrassRing / SuccessFactors / Phenom / Workday 各一套,还有 7 家是认不出厂商的 JS 门户;ats 域只会 7 家厂商;105 家 ≥50 岗的雇主才盖 67%。Jobillico 已把两千多家归一成同一份 JobPosting,它就是归一后的源头。

**形制**:`etl/jobillico/` 与 `etl/jobboom/` 各五件套(一站一域,同形不共码),四步链 sitemap → details → parse → store:

| 步 | 做什么 | 落哪 |
|---|---|---|
| sitemap | 索引 → 职位子图 → 帖号 → 详情 URL(Jobillico 同帖号英法取英文;Jobboom 剔 `job-bank`) | raw/<站>/urls.json |
| details | 未缓存的帖 → 详情原文,每轮封顶 `DETAILS_PER_RUN`(默认 3000,每秒两页) | crawl/board-<站>/(**crawl 域新开批量写门 `put_cached_pages` + 读索引 `load_cache_index`**:单页门每页重写整份 manifest,四万页 O(n²) 撑不住) |
| parse | 正则取 `<script type=ld+json>` 块(不整页建 DOM)→ JobPosting → 事实行,增量 | raw/<站>/jobs.json |
| store | 事实 × 枚举 → Job Bank 仓同键的行;不在站点地图 / 过 validThrough / 无标题的剔;落盘持 Job Bank 仓锁 | processed/<站>/postings.json |

值级清洗全在板域的 to_*(薪资拼成 Job Bank 写法「$25.00 hourly」、employmentType 译成 permanent/full 等 Job Bank 词);跨源清洗归 mart。

**mart 接法**:常量表 `IN_BOARD_STORES`(路径, origin)一站一行,评分收集 / 岗位装配 / 地点 / 薪资 / 试点打标五处各按表多走一轮,行级判定全部复用 Job Bank 的同一把尺子;externalId = `<板名>:<帖号>`,origin = 板名(渠道筛选多两个值),source = 板名,正文随行下沉(板帖没有 .md)。板帖不进验尸,过期由板域按截止日出仓。

**首轮实测**(DETAILS_PER_RUN=150):两域四步全过,ruff / pyrefly 零错;Jobillico 166 行(薪资填充 60/166,工时 149/166,地址带邮编),Jobboom 151 行(枚举 3,468,剔转载 21,433)。

**法文标题英译**(同日追加,Frank「能修复吗」):实测 NOC 分类器对法文标题只中 9%(140 条 13 中),英文页试过标题仍是法文(雇主只写法文),翻译是唯一出路。jobillico 域加第 5 步 `titles`:仅法文帖的标题 → 本地盒子 qwen3.6(照 pte 域 pte-zh 的 20 条一批编号行协议,温度 0)→ raw/jobillico/titles_en.json 只译一次,每轮上限 4,000 条;store 步 title 换英译、原文留 `title_orig`。实测 140 条零失败批,命中率 9% → **59%**(82/140),与英文帖持平(54%);样例 Contremaître de chantier → Site Foreman、Couvreur membrane → Membrane Roofer。首撞:响应文本过了折空白的 text_of 把编号行折成一行,批批解析失败 —— 响应原样取。

**上线路径**:compose 已加 jobillico / jobboom 两个 service;`docker compose up -d --build jobillico jobboom` 起容器后小时更,Jobillico 首轮约 12 轮抓满(标题英译首轮 1.3 万条分四轮);load 域 build 链下一轮自动带板帖汇装上传。**未验项**:板帖在职位板页面的显示(来源标签走 source_label 兜底原名);英文帖 54% 的命中率是分类器本身对泛标题(Lumber Yard Associate)的上限,与 ATS 岗同一口径。
