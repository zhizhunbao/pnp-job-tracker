### 3.3 Frank 四问的答案

- **年份 / 月份筛选:不加。** 列就是年份;StatCan 是季度、IRCC 是年度,月份筛选背后没有数据。
- **趋势是表格固有功能,不是操作列**(Frank 第八轮「趋势按钮不是放到操作上去,而且表格固有的功能」,推翻上一行的答案):通用 `components/table` 加「序列表」能力 —— 列是时间点的表,**表格自己的工具条**(表壳内、网格上方、右对齐,不是分区标题右槽 —— Frank 第十轮「应该放到表格上面,是一个小图标,待切换的」)放两枚图标钮 表 / 折线(lucide Table / ChartLine,亮色 = 当前态)+ 年份范围小字「近 5 年 · 全部」;手机卡头同两枚图标。终态效果图 `img/pulse-prov7-20260906-desk-5.png`(全国表态)、`-desk-2.png`(ON 趋势态)、`-mob-1.png`(手机卡)。趋势态 = **一张图多根线**(Frank 第九轮「趋势是一个图里有多根线吧」):每个指标一根线,y 轴用指数(该指标首个有值年份 = 100),图上方图例带颜色与最新原值,悬停显原值;量纲差六个数量级也能同图看走势。终态效果图 `img/pulse-prov6-20260906-desk-2.png`(ON 趋势态)。年份范围「近 5 年 / 全部」两态胶囊 Frank 第九轮拍板。任何年份列的表自动有,业务桶不自造。操作列只剩招聘对比的「看岗位」。效果图 `img/pulse-prov5-20260906-desk-2.png`(ON 趋势态)、`-desk-5.png`(全国表态;图里胶囊高亮反了,实现时表态亮「表」)、`-mob-1.png`(手机卡头同一对胶囊)。
- **年份范围**(Frank 第八轮「年份现在是最近 5 年的,是不是需要一个自定义字段按钮,把之前的年份也加进来」):同一右槽再加一对「近 5 年 / 全部」,也是序列表固有功能;「全部」= 来源有多少年给多少年(人口 StatCan 回溯到 1971 季度,临时居民 17-10-0121 从 2021 起,IRCC PR / 学签新签 2015 起),桌面表列变窄但固定布局不横滚,手机在趋势态看全部。不做逐列勾选的字段选择器(控件多,且 09-04 拍板「不让用户筛」)。数据层按「全部」抓,不只抓 5 年。
- **紧缺清单岗列:删。** 招聘对比只留 在招职位 / 近 7 天发布 / 中位年薪(ESDC)/ AIP 指定雇主岗 / 操作。

**B. 招聘对比横表**(Frank「招聘的数量没法按年份,可以按省份对比」):省份 / 在招职位 / 近 7 天发布 / 中位年薪(ESDC)/ AIP 指定雇主岗 / 操作(看岗位);右槽 Job Bank 日期;可排序。放在宏观表之后。

**撤**:原七列混表、省内职业榜、省卡、切省下拉与 chips、该省提名通道标签行(Frank「省份的就没必要细分到职位了」)。派生指标(竞争比、每千临时居民在招岗、同比)本批不做(Frank「先不要做那么多派生子表」)。
