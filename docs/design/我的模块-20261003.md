# 我的模块:顶栏入口 + 我的简历 / 我的收藏 / 我的求职 + 设置页(2026-10-03)

> Frank 10-03:「我的是不是应该放到 head 一个模块」「我的模块要先设计吧」。
> 接 [付费闭环-20261003](付费闭环-20261003.md)(四道题 → 注册 → 投递页 → 第 4 封定价)与 [站内投递批2-3](站内投递批2-3-简历上传与代投-20260923.md)(09-23 v4 效果图、「不做」清单)。
> 做法:别家调研(LinkedIn / Indeed / Jobright / Simplify / Huntr / Wobo / Massive)+ 代码盘点 + 三个角度各出一版(回访优先 22 分、极简复用 25 分、付费转化 24 分),以极简复用为骨架合成;与已拍冲突的一律以已拍为准(见末节)。

## 为什么现在做

「我的求职」是付费链的回访点:投完简历,用户回来看雇主有没有回信。别家惯例(LinkedIn Job tracker、Indeed My jobs、Simplify Emails 页签):默认落投递列表,状态由系统自动得出,点开看往来;档案偏好与订阅不放在投递列表里。

## 用户故事

### 顶栏入口

1. 作为登录用户,我在电脑顶栏导航末位看到「我的」(英文 My jobs);手机上它在汉堡抽屉里(照 09-23 v4)。访客看不到这一项。
2. ~~作为投过简历的人,有新回信或退信时「我的」带红点;手机上红点同时挂在汉堡钮和抽屉项上。我打开「我的求职」,红点灭。~~ 10-03 Frank「为什么要带红点」→ 不做:回信原样转发到用户邮箱,邮箱就是提醒;红点只对正在逛站的人有用,还要多记「看过时刻」。以后数据显示有人专门回来看「我的求职」再议。

### 页面结构

3. 作为用户,我进「我的」(/account)看到一栏:电脑照 v4 banner 版(banner 里 H1「我的」+ 通用 Tabs),手机照 v4 手机图;页签顺序照旧:我的简历 / 我的收藏 / 我的求职;退出登录只在头像下拉里。
4. 作为用户,我每次进来都落在「我的求职」。深链 `?sec=resume|favs|sjobs`;`&app=<id>` 直接打开某一条往来(回信转发邮件末尾就带这条链接);`?ok=1` 付款成功提示照旧。

### 我的求职

5. 作为求职者,电脑上我看到职位板形态的表(投递时间 / 公司 / 职位(译名灰注)/ 状态),手机上一岗一张职位卡;状态用标签:雇主已回复(绿)、已投递、退信(灰)。雇主已回复的置顶,其余按投递时间倒序。
6. 作为求职者,我点一行打开往来弹框(手机整屏):上面职位卡,下面往来表,一条一行(时间、发出 / 收到 / 退信、标题),点行展开原文;底部一个「查看职位」。
7. 作为还没投过的人,我看到「还没有投递」+「去职位板」。

### 我的收藏

8. 作为收藏过岗位的人,我看到职位卡,右上勾选框;投过的挂「已投递」、下架的挂「已下架」,这两种不能勾,也不删卡。
9. 作为勾了 N 个的人,我看到底栏「批量投递 N 个」(手机固定在底);后台逐封排队发,每天最多 20 封,超额照 09-23(额度内照发、弹定价框、没发的保持勾选)。
10. 作为想取消收藏的人,我回职位页点星;列表里不加钮。空态「还没有收藏」+「去职位板」。

### 我的简历

11. 作为用户,我看到两张白卡:简历卡(文件名点开预览、上传日、替换、删除;没传过只有「上传简历」);求职信模板卡(首行 +「编辑」「上传」;编辑在弹框多行框里改,职位名、公司名两处占位)。现在的文本存档界面退役,抽出的文字照样存,供匹配用。

### 设置页(头像下拉加「设置」,/settings,照职位详情页骨架:右上返回 + H1 + 白卡)

12. 作为用户,**档案卡**:四行(目标 / 专业 / 想做的工作 / 所在省)+「修改」,打开付费闭环批 A 的四题弹框,答案预填。
13. 作为用户,**邮件卡**:周报开关;存的搜索列成表,每行可删。
14. 作为卡订阅用户,**订阅卡**:套餐、下次扣款日、金额 +「取消订阅」;确认框只有一个钮,不挽留;取消后显示「有效至 X」+「恢复订阅」;换卡、发票交给 Stripe 客户门户。微信 / 支付宝买的包只写到期日 +「续买」。季付扣款前 7 天由 Stripe 发续费提醒。

## 冲突处理(以已拍为准)

1. 回访优先版把「我的求职」排第一格 → 以 v4 为准,顺序不变,只改默认落点。
2. 回访优先版把手机「我的」放汉堡钮左边 → 以 v4 为准,放抽屉。
3. 极简复用版「电脑不出表格」→ 以 v4 网页图为准,电脑表、手机卡。
4. 付费转化版批量投递逐个进投递页 → 以 09-23 为准,后台逐封排队。
5. 回访优先版退信标红 → 以 v4 为准,灰。
6. 09-23 的投递框 → 以 10-03「投递单开一页」为准;往来详情只读,仍用弹框。
7. 新页骨架要求右上返回,v4「我的」没有 → 以 v4 为准(顶栏一级入口);/settings 是下钻页,带返回。
8. 极简复用版订阅跳 Stripe 门户 → 以批 S「一键取消 + 续费提醒」为准,取消钮在站内。
