# /zhengli = 盘点 → 报数 → 一次问清 → 清 → 推

来源:2026-10-08 Frank「docs 目录也整理一下吧,现在历史文件和目录太多了」→「历史的都删了,只保留最新现状」→ 那一轮 docs/design 从 45 份稿 / 375 张图 75MB 清到 21 份 / 40 张 7MB,STATUS.md 从 8 月 29 日那版重写成当天现状。判据只有一条:**仓库里只放当前现状,历史在 git 里,不留两份真相。**

## 第 1 步 · 盘点(只读,出一张数表)

逐项数清,别凭印象:

- **docs/design/**:每份稿的日期与主题;哪些被同主题的后稿替代、哪些讲的功能已经撤了、哪些是调研稿且结论已经进了后稿;效果图 html 被哪份稿引用。
- **docs/design/img/**:每张图被谁引用 —— 扫 docs、STATUS.md、CLAUDE.md、.claude、cms/src、etl 里的 .md / .html / .ts / .tsx / .py(跳过 node_modules、data、.next、img 自己),文件名没出现在任何一处 = 没人引用。用 Python 一次读进内存比对(`git ls-files` + `os.walk`),别 grep 全仓逐张跑,375 张跑了五分钟超时。
- **STATUS.md**:§1「当前状态」的日期离今天多久;主线表的格有没有已经迈过的;§4 路标说的目录现状对不对;链到的稿还在不在。
- **CLAUDE.md**:只查**事实数字和路径**(域数、容器数、样张路径还在不在),规则本身一条不动。
- **.claude/**:worklog / 临时索引 / patch;`git worktree list` 有没有遗留树;skills 目录里没在用的脚本。
- **根目录与 cms/**:`.tmp-*`、`*.bak`、乱放的 md / html / 截图;ignored 的大目录(backups、reports、.next、data/crawl)只报体积不删。
- **git**:`.git` 体积与 pack 大小,只报不动。

数表格式:`目录 | 跟踪文件数 | 体积 | 其中可清 | 理由`。

## 第 2 步 · 报数 + 一次问清

把数表和删除清单的**判据**(不是逐个文件)发给 Frank,用 `AskUserQuestion` 一题三选:「只留最新现状(删被替代的稿 + 无引用图 + 临时件)」「只删图和临时件,稿不动」「按主题分子目录,不删」。Frank 10-08 选的是第一种,以后默认推荐它。

**永远不动的**(问都不用问):`docs/sql/`(生产 DDL,永不清仓)、`data/`(ETL 产出,属于各域)、代码、git 历史(重写历史会动所有克隆与 Render)、ignored 的本机目录。

## 第 3 步 · 清(照 Frank 选的做)

- **稿**:每个还活着的主题只留最新一份;被后稿替代、功能已撤(查 STATUS / 记忆里的「已删」「已撤」)、调研已消化的删。代码注释里指向被删稿的「指路」留着不改 —— 稿在 git 历史里,先例是 8 月的稿早就这么删了。
- **图 / 效果图 html**:先删稿,再重扫一遍引用,没人引用的全删(随稿退役的图会在第二遍冒出来)。
- **STATUS.md**:不是改几行,是**按今天的现状重写**五段(状态速览 / 主线表 / 计划与排队 / docs 路标 / 接手红线),事实来源 = 记忆里的拍板 + git log + 线上实况;写明「X 月 X 日重写,旧版沉 git」。
- **CLAUDE.md**:只改过时的数字和失效的路径,规则与带日期的决策记录一字不删。
- **临时件**:自己 session 的 `.tmp-*` 直接删;别的 session 的先看内容和 mtime,通用小工具或超过一周没动的报给 Frank 让他定。
- `git rm` 带 pathspec 提交(并行 session 共用索引,见 CLAUDE.md 原则 3),提交信息写清删了几份 / 几张 / 留了几份与判据,带 `[skip render]`,**单独推**(别压在代码提交上面)。推完 `git status -sb` 无 ahead。

## 第 4 步 · 收口一句

汇报:整前 / 整后的数(稿、图、体积)、留下的稿按主题列一行、哪些没动及为什么、留下的尾巴(比如 STATUS 里链到已删稿的那行)。

## 不许

- 不许删 docs/sql、data/、代码、.gitignore 里的本机目录;不许 `git filter-repo` / 改历史;不许动别的 session 正在写的文件;不许为了「整齐」把稿按构造改名或合并(一案一文件带日期是定下的形)。
